Section 17: Functions

Throughout this course, we've worked with equations like $y = 2x + 3$ and $y = x^2 - 4x + 3$. We've graphed them, solved them, and used them to model real situations. Now we step back to understand a fundamental concept that underlies all of this work: the function.

Before we can properly define what a function is, we need to introduce some basic ideas about sets. This may seem abstract at first, but it will give us a precise way to talk about functions—and you'll see that the equations and graphs you've already studied are concrete examples of these abstract ideas.

17.1 Sets and Functions

17.1.1 Sets and Elements

Two concepts form the foundation for everything that follows:

Core Definitions: Set and Element

A set is a collection of distinct objects, considered as a single entity.

An element (or member) is an object that belongs to a set.

These concepts are inseparable: a set is defined by its elements, and the idea of an element only makes sense in relation to a set it belongs to.

We write sets using curly braces. For example, $\{1, 2, 3\}$ is the set containing the elements 1, 2, and 3. We often name sets with capital letters:

$A = \{1, 2, 3, 4, 5\}$

The symbol $\in$ means "is an element of." We write $3 \in A$ to say "3 is an element of $A$." The symbol $\notin$ means "is not an element of," so $7 \notin A$ says "7 is not an element of $A$."

Examples of Sets and Their Elements

(a) A finite set of integers: $A = \{1, 2, 3, 4, 5\}$

The elements of this set are 1, 2, 3, 4, and 5. We can say $3 \in A$ (true) and $7 \notin A$ (also true). This set has exactly five elements.

(b) A set of colors: $B = \{\text{red}, \text{blue}, \text{green}\}$

The elements are the colors red, blue, and green. Note that $\text{red} \in B$, but $\text{yellow} \notin B$. Elements don't have to be numbers—they can be any kind of object.

(c) The set of students in a classroom: Let $S$ be the set of students in a classroom. Each student is an element of $S$. If Alice is in the class, then Alice $\in S$. The set $S$ changes if a student joins or leaves the classroom.

(d) The set of all integers: $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$

This is an infinite set—it has infinitely many elements. We have $47 \in \mathbb{Z}$ and $-1000 \in \mathbb{Z}$, but $1.5 \notin \mathbb{Z}$ (since 1.5 is not an integer).

(e) The set of all real numbers between 0 and 1: Let $D$ = the set of all real numbers between 0 and 1. Like $\mathbb{Z}$, the set $D$ is also infinite—in fact, it contains uncountably many elements. We have $0.5 \in D$ and $0.999 \in D$, but $2 \notin D$.

Set-Builder Notation

When working with sets frequently, it's useful to have a standard way to define them in terms of their membership. A common notation is:

$S = \{x \mid x \text{ satisfies some property}\}$

This notation may look odd at first, but it avoids confusion. The vertical bar "$\mid$" is read "such that," so the expression reads: "$S$ is the set of all $x$ such that $x$ satisfies some property."

Let's rewrite our examples using set-builder notation:

Examples (a)–(e) in Set-Builder Notation

(a) $A = \{x \mid x \text{ is an integer and } 1 \leq x \leq 5\} = \{1, 2, 3, 4, 5\}$

(b) $B = \{x \mid x \text{ is one of the colors red, blue, or green}\}$

(c) $S = \{x \mid x \text{ is a student in the classroom}\}$

(d) $\mathbb{Z} = \{x \mid x \text{ is an integer}\}$

(e) $D = \{x \mid x \in \mathbb{R} \text{ and } 0 < x < 1\}$

We'll use this notation throughout Section 17 when defining sets precisely.

Key Properties of Sets

Order doesn't matter: $\{1, 2, 3\} = \{3, 1, 2\}$. These are the same set—they contain the same elements.

No duplicates: $\{1, 1, 2\} = \{1, 2\}$. Listing an element twice doesn't change the set.

Sets can contain any kind of object: numbers, colors, people, shapes, even other sets.

Sets can be finite or infinite: $\{1, 2, 3\}$ is finite; the set of all integers is infinite.
Going Deeper: Can Sets Contain Themselves?

We said sets can contain "any kind of object—even other sets." This seems straightforward: we might have a set of sets, like $\{\{1, 2\}, \{3, 4\}\}$. But when logicians in the early 1900s pushed this idea to its limits, they discovered something troubling.

In 1901, the British philosopher and mathematician Bertrand Russell posed a devastating question: Consider the "set of all sets that do not contain themselves." Call it $R$. Now ask: Does $R$ contain itself?

If $R$ contains itself, then by definition (it's the set of sets that don't contain themselves), it shouldn't contain itself. But if $R$ doesn't contain itself, then it meets the membership criterion, so it should contain itself. Either answer leads to a contradiction.

This is Russell's Paradox, and it shook the foundations of mathematics. The "set of all sets" and self-referential set definitions turned out to be more dangerous than anyone expected. Mathematicians eventually developed careful rules (called axiomatic set theory) to prevent such paradoxes, essentially by restricting what collections can be called "sets."

For our purposes, we'll work only with well-behaved sets where membership is clear and unambiguous. But this episode reminds us that even seemingly simple concepts—like "a collection of objects"—can harbor surprises when examined closely.

17.1.2 Mappings Between Sets

A mapping is a rule that associates elements of one set with elements of another set. We visualize this with two "clouds" (sets) and arrows connecting elements:

  • The left cloud is the domain—the set we're mapping FROM
  • The right cloud is the codomain—the set we're mapping TO
  • Arrows show which input element goes to which output element

There's an important distinction we need to make right away:

Codomain vs. Range

The codomain is the entire set we've declared as "possible outputs." It's part of the mapping's specification—we choose it when we define the mapping.

The range (or image) is the subset of the codomain that actually gets hit by arrows—the outputs that actually occur.

The range is always contained within the codomain, but they may not be equal.

Now let's express something familiar in our new language. The equation $y = 2x + 1$ defines a mapping:

  • Domain: All real numbers (any $x$-value is allowed)
  • Codomain: All real numbers (we're mapping to $y$-values)
  • Rule: Each $x$ goes to $2x + 1$
  • Range: All real numbers (every real number is hit—for any $y$, solve $2x + 1 = y$ to get $x = \frac{y-1}{2}$)

This is the line you graphed in Section 12. Every point $(x, y)$ on the graph represents an arrow from $x$ to $y$. The graph IS the mapping, visualized.

Example (e): The Parabola y = x²

Here's another familiar equation, but this time the range does NOT equal the codomain:

  • Domain: All real numbers
  • Codomain: All real numbers (as typically stated)
  • Rule: Each $x$ goes to $x^2$
  • Range: Only non-negative real numbers ($y \geq 0$)

The parabola never dips below the $x$-axis, so negative $y$-values are in the codomain but never in the range. This is a concrete example of the codomain/range distinction. 17.1.3 Functions: Mappings That Are Single-Valued

Not all mappings are created equal. Let's first understand the general concept, then identify the special property that makes certain mappings extraordinarily useful.

Definition: Relation

A relation is any mapping between sets—arrows can branch (one input to multiple outputs) or be absent. There are no restrictions on how elements are connected.
Definition: Function

A function is a special kind of relation where every element of the domain has exactly one arrow leaving it.

This means two things:
• Every domain element must have an arrow (no missing outputs)
• No domain element can have more than one arrow (no branching)

Key insight: Every function is a relation, but not every relation is a function.

Functions vs. Relations

A relation is any mapping between sets—arrows can branch (one input to multiple outputs) or be absent. A function is a special kind of relation: single-valued, with every input having exactly one output.

Every function is a relation, but not every relation is a function.

Consider the circle $x^2 + y^2 = 25$. This equation determines a mapping $y = \pm\sqrt{25 - x^2}$. This mapping is a relation whose domain is $\{x \mid -5 \leq x \leq 5\}$ and whose range is $\{y \mid -5 \leq y \leq 5\}$. Looking at the graph, we can see that each value of $x$ in the domain (visualized by a vertical line) maps to two values of $y$, so this relation is not a function.

Why Functions Matter

Functions aren't just an abstract concept—they're central to how mathematics connects to the real world. The key property is predictability: a function guarantees that the same input always produces the same output.

Functions Are Essential For:

Science: Physical laws are functions. If you drop an object from 10 meters, the time to fall is determined by the height—not random. Physics couldn't exist if the same conditions sometimes gave different results.

Engineering: When an engineer designs a bridge, they use functions that relate load to stress, material properties to strength. The bridge's safety depends on these relationships being predictable.

Computing: Every program is built from functions. When you type "2 + 2" into a calculator, you expect 4 every time—not sometimes 4 and sometimes 5.

Economics: Supply and demand curves, cost functions, pricing models—all functions. Businesses make decisions based on predicted outcomes.

The key insight: A world where the same situation could produce different outcomes would be unpredictable and unlearnable. Functions capture the idea of deterministic relationships—and most of what we understand about the world comes from identifying and studying such relationships.

Figure 17.7: Domain, codomain, and range. (a) When every codomain element is hit, Range = Codomain. (b) When some codomain elements are unhit, Range is a proper subset of Codomain. (c) For $y = x^2$ with codomain all reals, the range is only non-negative reals—a specific example of case (b).

Why the Distinction Matters

When we define a function, we declare both the domain (inputs) and the codomain (possible outputs). The range is then determined by the mapping rule—it's what we actually hit.

We choose the codomain. We discover the range. But our choice of codomain must contain the range—every actual output must be in the set of "possible outputs."

Two functions with the same rule but different codomains are technically different functions, and they may have different properties (as we'll see with "onto" functions).

A Closer Look at y = x²: Two Perspectives

The equation $y = x^2$ provides an illuminating example. Let's examine it from two perspectives:

View 1: y as a function of x

  • For each $x$, compute $x^2$ to get exactly one $y$
  • This IS a function (each input has one output)
  • But it's NOT one-to-one: both $x = 3$ and $x = -3$ give $y = 9$

View 2: x as a function of y

  • Given a $y$-value, try to find the corresponding $x$
  • For $y = 9$: is $x = 3$ or $x = -3$? Both satisfy $x^2 = 9$
  • We cannot assign a single $x$ to this $y$
  • This is NOT a function—it's a relation

Figure 17.9: The parabola $y = x^2$ with two test lines. The vertical line test (blue, at $x = 2$) shows one intersection—$y$ is a function of $x$. The horizontal line test (red, at $y = 4$) shows two intersections—$x$ is NOT a function of $y$, and the original function is not one-to-one.

Two Useful Tests

Vertical Line Test: If every vertical line crosses the graph at most once, then $y$ is a function of $x$. (Each $x$ has at most one $y$.)

Horizontal Line Test: If every horizontal line crosses the graph at most once, the function is one-to-one. (Each $y$ comes from at most one $x$.)

The parabola passes the vertical line test (it's a function) but fails the horizontal line test (it's not one-to-one).

Why One-to-One Matters: Inverse Functions

One-to-one functions have a special property: they can be reversed. If $f$ takes you from input to output, an inverse function $f^{-1}$ takes you back from output to input.

Consider why this works only for one-to-one functions:

Dashed arrows show the inverse

Not one-to-one: Can't reverse

$f(x) = x^2$: Both $-2$ and $2$ map to $4$

If given 4, which $x$ do we go back to?

Figure 17.8b: Why one-to-one enables inverses. Left: $f(x) = 2x+1$ is one-to-one, so each output uniquely identifies its input—we can reverse the arrows. Right: $f(x) = x^2$ is not one-to-one (both $-2$ and $2$ map to $4$), so given output $4$, there's no unique way back.

This explains a convention you may have encountered: why does $\sqrt{4} = 2$, not $\pm 2$? The square root function is defined as the inverse of squaring, but squaring isn't one-to-one on all real numbers. To make an inverse possible, we restrict the domain to non-negative numbers only. On this restricted domain, squaring becomes one-to-one, and $\sqrt{y}$ gives the unique non-negative $x$ such that $x^2 = y$. If we want both roots, we write $y = \pm\sqrt{x}$—but this notation is a convention, a shortcut, since we usually want the positive root.

The Inverse Function Pattern

Many important functions come in inverse pairs: addition/subtraction, multiplication/division, exponentiation/logarithms, squaring/square roots, sine/arcsine, etc.

For an inverse to exist, the original function must be one-to-one—or we must restrict its domain to make it so. In the example above, we restricted the domain of $y = x^2$ to $x \geq 0$ so that the squaring function would have an inverse (the square root).

This is also why inverse trigonometric functions (which we'll meet in a later course) have restricted ranges: the underlying trig functions repeat their values periodically, so we artificially limit the "return trip" to a single interval where each output value occurs only once.

Here's a subtle but important point: whether a function is onto depends on what you declare the codomain to be.

17.1.7 Bijections: One-to-One AND Onto

Definition: Bijection

A function that is both one-to-one AND onto is called a bijection (or a one-to-one correspondence).

Visually: every domain element has exactly one arrow leaving, and every codomain element has exactly one arrow arriving. A perfect pairing with no sharing and no orphans.
(a) Students ↔ Lockers
BIJECTION ✓

Perfect pairing

(b) C → F temperature
BIJECTION ✓

1-1 and onto

(c) y = 2x + 1
BIJECTION ✓

Linear functions are bijections

Figure 17.12: Bijection examples. (a) Each student has one locker, each locker has one student. (b) Celsius to Fahrenheit is a bijection—different temps give different results, and every Fahrenheit value corresponds to some Celsius value. (c) Any linear function $y = mx + b$ (with $m \neq 0$) is a bijection on the reals.

Why Bijections Matter

1. Inverses exist. A bijection can be "undone"—we can go from outputs back to inputs unambiguously. If a function is not one-to-one, we can't tell which input produced a given output. If it's not onto, some outputs don't come from any input. Only bijections can be fully reversed.

2. Perfect correspondence. Bijections show that two sets have "the same size" in a precise sense. If there's a bijection between set $A$ and set $B$, they have the same number of elements. From an element point of view, if $f$ is a bijection from $A$ to $B$, each element $y$ in $B$ has a unique counterpart $x$ in $A$, and conversely. (This idea extends even to infinite sets, where it becomes the concept of "cardinality.")

Summary: Classifying Functions

We've seen several functions. Let's classify them:

3. Mapping: $a \to 2$, $b \to 2$, $c \to 4$

(a) Domain: $\{a, b, c\}$

(b) Codomain: $\{1, 2, 3, 4\}$

(c) Range: $\{2, 4\}$ (only 2 and 4 are actually hit)

(d) Yes, it's a function. Each domain element ($a$, $b$, $c$) has exactly one arrow leaving it. The fact that $a$ and $b$ both map to 2 is fine—outputs can be shared.

4. Mapping: $1 \to x$, $2 \to y$, $2 \to z$, $3 \to x$

(a) No, this is NOT a function. The element 2 has two arrows leaving it (to $y$ and to $z$). A function requires exactly one output per input.

(b) To make it a function, we would need to remove one of the arrows from 2. For example: $1 \to x$, $2 \to y$, $3 \to x$ would be a function.

5. $y = 3x - 2$

(a) Range: all real numbers. For any real number $y$, we can solve $3x - 2 = y$ to get $x = \frac{y + 2}{3}$, which is also a real number. So every real $y$ is hit.

(b) Yes, it's a function. For each input $x$, there is exactly one output $y = 3x - 2$. The formula uniquely determines $y$ from $x$.

6. $y = x^2 + 1$

(a) The smallest value occurs when $x^2$ is smallest, which is when $x = 0$. Then $y = 0 + 1 = 1$.

(b) Range: $[1, \infty)$ or equivalently $y \geq 1$. Since $x^2 \geq 0$ for all real $x$, we have $y = x^2 + 1 \geq 1$.

(c) No. The codomain is all real numbers, but the range is only $y \geq 1$. Values like $y = 0$ or $y = -5$ are in the codomain but not in the range.

7. Example: $y = x^2$

Domain: all real numbers

Codomain: all real numbers

Rule: square the input

Range: non-negative reals ($y \geq 0$)

The range is a proper subset because negative numbers are in the codomain but never produced as outputs.

8.

(a) $y = 5x$: One-to-one. If $5a = 5b$, then $a = b$. Different inputs give different outputs.

(b) $y = x^2 - 4$: Not one-to-one. For example, $x = 2$ and $x = -2$ both give $y = 0$. Different inputs, same output.

(c) $y = x^3$: One-to-one. If $a^3 = b^3$, then $a = b$. Each real number has a unique cube.

9. $y = |x|$

(a) Yes, it's a function. For each input $x$, there is exactly one output $|x|$ (the distance from $x$ to 0).

(b) Not one-to-one. For example, $|3| = 3$ and $|-3| = 3$. Different inputs give the same output.

10.

(a) $y = 2x - 1$ (ℝ → ℝ): Onto. For any real $y$, solve $2x - 1 = y$ to get $x = \frac{y+1}{2}$. Every $y$ is hit.

(b) $y = x^2$ (ℝ → ℝ): Not onto. Negative values of $y$ are never hit (no real $x$ gives $x^2 < 0$).

(c) $y = x^2$ (ℝ → $[0,\infty)$): Onto. Every non-negative $y$ is hit: $y = (\sqrt{y})^2$.

11. Domain: $\{1, 2, 3\}$ (3 elements). Codomain: $\{a, b\}$ (2 elements).

Onto? Yes, it's possible. Example: $1 \to a$, $2 \to b$, $3 \to a$. Both $a$ and $b$ are hit.

One-to-one? No, impossible. With 3 inputs and only 2 outputs, by the pigeonhole principle, at least two inputs must share an output.

12.

(a) $y = -3x + 7$ (ℝ → ℝ): (i) Bijection. One-to-one (linear with non-zero slope) and onto (every real $y$ is $-3x + 7$ for some $x$).

(b) $y = x^2$ ($[0,\infty) \to [0,\infty)$): (i) Bijection. One-to-one on non-negative reals (no more $\pm$ issue) and onto the non-negative reals.

(c) Students → birthdays: (iii) Onto but not one-to-one (if we assume all possible birthdays in a year are represented, which is unrealistic for a small class) OR more likely (iv) neither (some birthdays aren't represented, and some are shared).

13. One possible bijection from $\{1, 2, 3, 4\}$ to $\{a, b, c, d\}$:

$1 \to a$, $2 \to b$, $3 \to c$, $4 \to d$

Many other bijections exist, such as $1 \to d$, $2 \to c$, $3 \to b$, $4 \to a$.

14. The circle $x^2 + y^2 = 9$ does not define $y$ as a function of $x$ because for most $x$-values, there are two corresponding $y$-values.

For example, when $x = 0$: $0 + y^2 = 9$, so $y = 3$ or $y = -3$.

A function must give exactly one output for each input. The circle gives two outputs (except at $x = \pm 3$), violating this requirement.

15. If $f$ is one-to-one, different inputs give different outputs. This means each output comes from exactly one input.

So given any output $y$ in the range, there's exactly one input $x$ that produced it. We can define $f^{-1}(y) = x$ (the inverse function), and this is well-defined because there's no ambiguity about which $x$ to choose.

If $f$ were NOT one-to-one, some output $y$ would come from multiple inputs, and we couldn't uniquely determine which one to "go back to."

17.2 Function Notation

In Section 17.1, we established what a function is: a mapping that assigns exactly one output to each input. Now we introduce the standard notation mathematicians use to work with functions efficiently.

17.2.1 The Notation f(x)

When we have a function, we give it a name—usually a single letter like $f$, $g$, or $h$. Then we write $f(x)$ to mean "the output of function $f$ when the input is $x$."

Function Notation: f(x)

In the expression $f(x)$:
• f is the function's name
• x is the input variable (also called the argument)
• f(x) represents the output—the value the function produces for input $x$

Pronunciation: "$f$ of $x$" (never "$f$ times $x$")

Think of a function as a machine: you feed in an input, and it produces an output. The notation $f(x)$ tells us which machine ($f$) and what we're feeding it ($x$).

Figure 17.13: A function as a machine. Input $x$ goes in, output $f(x)$ comes out. The function $f$ is the rule that determines how inputs become outputs.

⚠ Critical Clarification: f(x) is NOT Multiplication

This is a major source of confusion for students learning function notation.

• In $f(x)$, the parentheses mean function evaluation, not multiplication
• $f(x)$ is a single symbol representing the output—it's not "$f$ times $x$"
• Compare: $3(x)$ means $3 \cdot x$ (multiplication), but $f(x)$ means "apply function $f$ to $x$"

The letter $f$ by itself is the function's name, not a number to multiply.

17.2.2 Defining a Function with a Formula

When we write $f(x) = 2x + 3$, we're defining a function named $f$ whose rule is "double the input and add 3." Here are some examples:

Example 1: Function Definitions

(a) $f(x) = 2x + 3$ — "double and add 3"
(b) $g(x) = x^2 - 4$ — "square and subtract 4"
(c) $h(t) = -16t^2 + 48t + 4$ — height of a ball at time $t$ (physics formula)
(d) $A(r) = \pi r^2$ — area of a circle with radius $r$

Notice that we can use any letter for the input variable ($x$, $t$, $r$), and we can give functions descriptive names like $A$ for area.

17.2.3 Connection to Equation Notation

You've already worked with equations like $y = 2x + 3$. Function notation $f(x) = 2x + 3$ describes the same relationship, but with some advantages:

Figure 17.14: Equation notation and function notation describe the same relationship. Function notation is more compact when specifying particular inputs.

The advantage of function notation: $f(5) = 13$ is more compact and precise than "when $x = 5$, $y = 13$." We can refer to specific outputs directly.

Equation Notation Function Notation
$y = 2x + 3$ $f(x) = 2x + 3$
When $x = 5$, $y = 13$ $f(5) = 13$
Graph points: $(x, y)$ Graph points: $(x, f(x))$

17.2.4 Functions and Their Graphs

When we graph a function, we often write $y = f(x)$ to emphasize that the $y$-coordinate of each point equals the function's output for that $x$-value.

Figure 17.15: Each point on a function's graph has coordinates $(x, f(x))$. The statement $f(2) = 7$ means the point $(2, 7)$ is on the graph.

The Graph of a Function

The graph of a function $f$ is the set of all points $(x, f(x))$ where $x$ is in the domain.

In other words: for each allowed input $x$, plot the point whose $x$-coordinate is the input and whose $y$-coordinate is the output $f(x)$.

17.3 Evaluating Functions

Evaluating a function means finding the output for a specific input. This is the most fundamental skill when working with functions.

17.3.1 Evaluating with Numerical Inputs

To evaluate $f(a)$ where $a$ is a number: substitute $a$ for every $x$ in the formula, then simplify.

Figure 17.16: Evaluating $f(3)$ when $f(x) = x^2 - 4$. Substitute 3 for $x$, then simplify.

Example 2: Evaluating with Numbers

Let $f(x) = 2x + 5$. Find: (a) $f(3)$   (b) $f(-2)$   (c) $f(0)$

Solution:

(a) $f(3) = 2(3) + 5 = 6 + 5 = 11$

(b) $f(-2) = 2(-2) + 5 = -4 + 5 = 1$

(c) $f(0) = 2(0) + 5 = 0 + 5 = 5$

Notice that $f(0) = 5$ gives us the $y$-intercept of the graph—the output when input is 0.
Example 3: Evaluating a Quadratic

Let $g(x) = x^2 - 4x + 3$. Find: (a) $g(1)$   (b) $g(3)$   (c) $g(-1)$

Solution:

(a) $g(1) = (1)^2 - 4(1) + 3 = 1 - 4 + 3 = 0$

(b) $g(3) = (3)^2 - 4(3) + 3 = 9 - 12 + 3 = 0$

(c) $g(-1) = (-1)^2 - 4(-1) + 3 = 1 + 4 + 3 = 8$

Since $g(1) = 0$ and $g(3) = 0$, the points $(1, 0)$ and $(3, 0)$ are on the graph—these are the $x$-intercepts.

17.3.2 Evaluating with Expression Inputs

Sometimes we need to evaluate a function at an expression rather than a number. The same rule applies: substitute the entire expression for every $x$.

Figure 17.17: Evaluating $f(a+1)$ when $f(x) = x^2$. The entire expression $(a+1)$ replaces $x$, so we get $(a+1)^2$, not $a^2 + 1$.

⚠ Common Error: Incomplete Substitution

When evaluating $f(a + 1)$ where $f(x) = x^2$:

✗ Wrong: $f(a + 1) = a^2 + 1$ (substituted only part of the expression)
✓ Correct: $f(a + 1) = (a + 1)^2 = a^2 + 2a + 1$ (substituted the whole expression)

The key: wherever you see $x$ in the formula, the entire input expression goes there, wrapped in parentheses.
Example 4: Expression Inputs

Let $f(x) = 2x - 3$. Find: (a) $f(t + 2)$   (b) $f(2h)$   (c) $f(x + 1)$

Solution:

(a) $f(t + 2) = 2(t + 2) - 3 = 2t + 4 - 3 = 2t + 1$

(b) $f(2h) = 2(2h) - 3 = 4h - 3$

(c) $f(x + 1) = 2(x + 1) - 3 = 2x + 2 - 3 = 2x - 1$
Example 5: Expressions with a Quadratic

Let $g(x) = x^2 + x$. Find $g(3a)$.

Solution:
Substitute $(3a)$ for every $x$:
$g(3a) = (3a)^2 + (3a) = 9a^2 + 3a$

17.3.3 Working Backward: Finding Input from Output

Sometimes we know what output we want and need to find the input that produces it. This connects function evaluation to equation solving.

Figure 17.18: Forward evaluation (top) finds output from input. Working backward (bottom) finds input from output by solving an equation.

Example 6: Finding the Input

If $f(x) = 3x - 7$ and $f(x) = 20$, find $x$.

Solution:
We need the input that produces output 20. Set the formula equal to 20 and solve:

$3x - 7 = 20$
$3x = 27$
$x = 9$

Check: $f(9) = 3(9) - 7 = 27 - 7 = 20$ ✓

Answer: $x = 9$
Example 7: A Practical Application

A game's damage formula is $D(s) = 10 + 2s$, where $s$ is the character's strength stat.

(a) If your strength is 15, how much damage do you deal?
(b) What strength do you need to deal 50 damage?

Solution:

(a) Evaluate at $s = 15$:
$D(15) = 10 + 2(15) = 10 + 30 = 40$ damage

(b) Work backward—find $s$ when $D(s) = 50$:
$10 + 2s = 50$
$2s = 40$
$s = 20$

Answer: (a) 40 damage; (b) strength 20

17.3.4 Summary: Evaluation Techniques

How to Evaluate Functions

For numerical inputs $f(a)$:
1. Replace every $x$ in the formula with the number $a$
2. Simplify the result

For expression inputs $f(\text{expression})$:
1. Replace every $x$ with the entire expression, using parentheses
2. Simplify (expand if needed)

To find input from output (when $f(x) = k$):
1. Set the formula equal to $k$
2. Solve the resulting equation for $x$

17.4 Domain and Range from Formulas and Graphs

In Section 17.1, we defined domain as the set of allowed inputs and range as the set of outputs that actually occur. Now we'll learn to find these from formulas and graphs—practical skills you'll use constantly when working with functions.

17.4.1 Visualizing Domain and Range

On a graph, the domain and range appear as the horizontal and vertical extents of the curve:

Domain and Range on a Graph

• Domain = the set of $x$-values for which the function is defined (horizontal extent)
• Range = the set of $y$-values that the function actually produces (vertical extent)

Think of it this way: project the graph onto the $x$-axis to see the domain, and project it onto the $y$-axis to see the range.
(a) Natural Domain

Domain: all real numbers
Range: $[-1, \infty)$

(b) Restricted Domain

Domain: $[-2, 2]$
Range: $[-1, 3]$

Figure 17.19: The parabola $f(x) = x^2 - 1$. (a) With its natural domain (all real numbers), the parabola extends infinitely left and right, and the range is $[-1, \infty)$ since the minimum value is $-1$ at $x=0$. (b) Sometimes we restrict the domain to match a problem constraint. If we choose the domain $[-2, 2]$, we get only part of the parabola, and the range becomes $[-1, 3]$.

17.4.2 Finding Domain from a Formula

For most functions given by formulas, the domain is "all real numbers" unless something in the formula creates a restriction. The two most common restrictions are:

Common Domain Restrictions

1. Division by zero is forbidden:
If the formula has $x$ in a denominator, exclude values that make the denominator zero.

2. Square roots of negatives are forbidden (for real numbers):
If the formula has $\sqrt{\text{expression}}$, require that expression $\geq 0$.
Example 8: Domain from Division

Find the domain of $f(x) = \dfrac{1}{x - 3}$.

Solution:
The denominator is $x - 3$. We need $x - 3 \neq 0$, which means $x \neq 3$.

Domain: All real numbers except 3, written as $\{x \in \mathbb{R} \mid x \neq 3\}$ or in interval notation $(-\infty, 3) \cup (3, \infty)$
Example 9: Domain from Square Root

Find the domain of $g(x) = \sqrt{x - 4}$.

Solution:
We need the expression under the radical to be non-negative:
$x - 4 \geq 0$
$x \geq 4$

Domain: $\{x \mid x \geq 4\}$ or in interval notation $[4, \infty)$
Example 10: Combined Restrictions

Find the domain of $h(x) = \dfrac{1}{\sqrt{x}}$.

Solution:
Two restrictions apply:
• Square root requires: $x \geq 0$
• Division requires: $\sqrt{x} \neq 0$, which means $x \neq 0$

Combining these: we need $x \geq 0$ AND $x \neq 0$, so $x > 0$.

Domain: $\{x \mid x > 0\}$ or in interval notation $(0, \infty)$
$f(x) = \frac{1}{x}$

Domain: $x \neq 0$

$g(x) = \sqrt{x}$

Domain: $x \geq 0$

Figure 17.20: Functions with domain restrictions. The dashed line at $x = 0$ in the left graph shows where $f(x) = 1/x$ is undefined (vertical asymptote). The solid dot at the origin in the right graph shows where the domain of $\sqrt{x}$ begins.

17.4.3 Context Restrictions

Sometimes a formula works mathematically for values that don't make sense in the real-world context.

Example 11: Context Limits the Domain

A ball is thrown upward. Its height in feet after $t$ seconds is $h(t) = -16t^2 + 48t + 4$.

Mathematical domain: The formula works for all real $t$ (no division or square roots).

Practical domain: Time can't be negative, and the ball lands when $h(t) = 0$.
Solving $-16t^2 + 48t + 4 = 0$ using the quadratic formula gives two solutions: $t \approx -0.08$ and $t \approx 3.08$. The quadratic always has two mathematical solutions, but the negative value makes no physical sense (we can't have negative time), so we discard it.

The practical domain is $\{t \mid 0 \leq t \leq 3.08\}$ or $[0, 3.08]$—from launch to landing.

17.4.4 Finding Range

Finding the range is often harder than finding the domain. For now, use these strategies:

Strategies for Finding Range

1. Look at the graph — what $y$-values are actually hit?

2. For familiar function types:
• Linear $f(x) = mx + b$ (with $m \neq 0$): Range = all real numbers
• Quadratic $f(x) = ax^2 + bx + c$: Range has a minimum (if $a > 0$) or maximum (if $a < 0$) at the vertex
• Square root $f(x) = \sqrt{x}$: Range = $y \geq 0$

3. Think about what outputs are possible — can the function produce negative values? Zero? Very large values?
Example 12: Finding Range

Find the range of $f(x) = x^2 + 1$ (domain: all real numbers).

Solution:
Since $x^2 \geq 0$ for all real $x$, we have $x^2 + 1 \geq 0 + 1 = 1$.
The minimum value is 1 (when $x = 0$).
There's no maximum—as $|x|$ grows, $f(x)$ grows without bound.

Range: $\{y \mid y \geq 1\}$ or in interval notation $[1, \infty)$

17.5 The Vertical Line Test

Given a graph, how can you tell if it represents a function? The vertical line test provides a quick visual check.

17.5.1 The Test

The Vertical Line Test

A graph represents a function if and only if every vertical line crosses the graph at most once.

• If any vertical line crosses the graph twice (or more), it's NOT a function
• If every vertical line crosses at most once, it IS a function

Why does this work? A vertical line represents all points with a single $x$-value. If the line crosses the graph twice, that means one input produces two different outputs—violating the function requirement (recall from 17.1: exactly one output per input).

Parabola: $y = x^2$
✓ Passes — Is a function
Line: $y = 2x - 1$
✓ Passes — Is a function
Circle: $x^2 + y^2 = 4$
✗ Fails — Not a function

Figure 17.21: The vertical line test. The red dashed line shows a test position. For the parabola and line, it crosses once. For the circle, it crosses twice—so the circle is not a function.

17.5.2 Examples: Pass and Fail

Example 13: Graphs That Pass

These represent functions:
• Any non-vertical line (vertical lines fail!)
• Parabolas opening up or down ($y = ax^2 + bx + c$)
• The graph of $y = \sqrt{x}$ (a "half parabola" lying on its side)
• The graph of $y = |x|$ (a V-shape)

In each case, any vertical line crosses the graph at most once.
Example 14: Graphs That Fail

These do NOT represent functions:
• Circles: $x^2 + y^2 = r^2$
• Horizontal parabolas: $x = y^2$ (sideways parabola)
• Vertical lines: $x = 3$
• Any graph that "doubles back" horizontally

For each of these, there exist vertical lines that cross the graph more than once.
⚠ Relation vs. Function

Recall from Section 17.1: A relation connects inputs to outputs but allows multiple outputs per input. A function is a special kind of relation where each input has exactly one output.

The equation $x^2 + y^2 = 4$ describes a relation (the set of points on a circle), but not a function. For example, when $x = 0$, we get $y = 2$ and $y = -2$—two outputs for one input.

17.6 Summary: Practical Function Skills

This section consolidates the practical skills from Sections 17.2–17.5. Use it as a quick reference when working with functions.

Key Definitions

Function: A rule that assigns exactly one output to each input. (For the formal treatment in terms of sets and mappings, see Section 17.1.)

$f(x)$: Function $f$ evaluated at input $x$. Read as "f of x" (not "f times x"). The parentheses indicate function evaluation, not multiplication.

Domain: The set of allowed inputs—all $x$-values for which the function is defined.

Range: The set of outputs that actually occur—the $y$-values the function actually produces.

One-to-one (injective): Different inputs always give different outputs. If $f(a) = f(b)$, then $a = b$.

Onto (surjective): Every element of the codomain is hit by at least one input.

Equation Notation vs. Function Notation

Function notation is more precise than equation notation when we want to talk about specific inputs and outputs:

Equation Notation Function Notation
$y = 2x + 3$ $f(x) = 2x + 3$
"When $x = 5$, $y = 13$" $f(5) = 13$
Graph points: $(x, y)$ Graph points: $(x, f(x))$
"The formula $y = x^2$" "The function $f$ where $f(x) = x^2$"

Both notations describe the same mathematical relationships. Function notation simply makes it easier to evaluate at specific values and to name different functions ($f$, $g$, $h$, etc.).

Evaluating Functions

To evaluate $f(a)$: Substitute $a$ for every occurrence of $x$ in the formula, then simplify.

Example: If $f(x) = x^2 - 3x + 2$, then
$f(4) = (4)^2 - 3(4) + 2 = 16 - 12 + 2 = 6$

This works for any input—numbers, expressions, or even other variables:

  • $f(a + 1)$: Replace $x$ with $(a + 1)$ everywhere
  • $f(-x)$: Replace $x$ with $(-x)$ everywhere
  • $f(2t)$: Replace $x$ with $(2t)$ everywhere

Finding Domain: Quick Reference

For most formulas, the domain is "all real numbers" unless the formula creates a restriction:

Division: Avoid Zero Denominators

If $x$ appears in a denominator, exclude values that make the denominator zero.

Example: $f(x) = \dfrac{1}{x-3}$ → Domain: $\{x \mid x \neq 3\}$

Square Roots: No Negatives Inside

If the formula has $\sqrt{\text{expression}}$, require that expression $\geq 0$.

Example: $g(x) = \sqrt{x-4}$ → Domain: $\{x \mid x \geq 4\}$

Combined Restrictions

Apply all restrictions that appear in the formula.

Example: $h(x) = \dfrac{1}{\sqrt{x}}$ → Domain: $\{x \mid x > 0\}$

Practical Context

Real-world problems may limit the domain further (time can't be negative, quantities must be positive, etc.).

Example: When Practical Considerations Limit the Domain

An audio engineer designing a speaker system might model the speaker's frequency response as a function $R(f)$, where $f$ is the frequency in Hertz (Hz). Mathematically, the formula might work for any positive frequency—from 0.001 Hz to 10 million Hz.

But humans can only hear frequencies between about 20 Hz and 20,000 Hz. Frequencies below 20 Hz are too low (infrasound); frequencies above 20,000 Hz are too high (ultrasound). So the engineer chooses a practical domain of $\{f \mid 20 \leq f \leq 20000\}$.

The function $R(f)$ might be perfectly well-defined at $f = 50000$ Hz, but there's no reason to care—no human would hear it. The mathematics works everywhere, but the application only matters on a restricted domain.

This is common in engineering and science: the mathematical domain (where the formula works) is often larger than the practical domain (where we actually need answers).

Functions and Graphs

Graphical Connections

Domain on a graph: Project the curve onto the $x$-axis. The domain is the horizontal extent—the set of $x$-values where the graph exists.

Range on a graph: Project the curve onto the $y$-axis. The range is the vertical extent—the set of $y$-values the curve actually reaches.

Vertical Line Test: A graph represents a function if and only if every vertical line crosses the graph at most once.

Horizontal Line Test: A function is one-to-one if and only if every horizontal line crosses the graph at most once.

The vertical line test works because a vertical line represents all points with a single $x$-value. If the line crosses the graph twice, that $x$-value produces two different outputs—violating the definition of a function.

17.7 Going Deeper: Functions as Mathematical Bridges

So far, we've treated functions as formulas that take number inputs and produce number outputs. But the function concept is far more general—and far more powerful—than this suggests. Functions are one of the most important ideas in all of mathematics because they allow us to build bridges between different mathematical worlds.

This section explores why functions matter so deeply. The material is more conceptual than computational—it's about understanding rather than calculating. Every abstract idea is grounded in concrete examples, and by the end, you'll see why functions are central not just to mathematics, but to science, engineering, and computer science.

17.7.1 The Foundation: Determinism

In Section 17.1, we emphasized that a function must give exactly one output for each input. The technical term for this property is determinism: given the same input, a function always produces the same output. This single-valuedness is what makes functions usable as tools for mathematics and science.

General Definition of Function

A function $f: A \to B$ assigns to each element of set $A$ exactly one element of set $B$.

$A$ is called the domain. $B$ is called the codomain.
The range (or image) is the subset of $B$ that actually gets hit by the function.

The sets $A$ and $B$ can be anything: numbers, words, geometric shapes, states in a system, records in a database. The function concept is about the mapping—the deterministic assignment of outputs to inputs—not about what kind of objects are being mapped.
Why This Generality Matters

If $f$ is a function mapping set $A$ to set $B$, and $x$ is in the domain of $f$, then there is a unique element $y$ of $B$ such that $f(x) = y$. This makes functions a foundation for the scientific method: for an input under given initial conditions, we should always get the same unique output.

If an input could give two different outputs, science would be in tatters.

Newton's Second Law: $F = ma$ (force equals mass times acceleration)
Ohm's Law: $E = IR$ (voltage equals current times resistance)

These are examples of a broad set of equations that use functions to express our understanding of nature. Given the inputs (mass and acceleration, or current and resistance), there is exactly one output (force, or voltage). This determinism is what makes physics predictive.
Going Deeper: Idealization and Noise

While functions are essential for understanding the physical world—Newton's laws, general relativity, Ohm's law—they are still idealizations that must be tempered with the imperfections of real-world measurements.

Scientists and engineers understand that their laws are approximations. In the real world, we can never measure things perfectly, and there are always fluctuations we can't fully control (often called "noise").

Example: Ball bearing on a ramp. If you build a ramp and try to start a ball at the top with zero velocity, measuring how far it travels after leaving the ramp, you won't get exactly the same answer each time. The starting velocity won't be exactly zero, there will be air currents, the surface won't be perfectly smooth, and so on. Our equation $F = ma$ will give us a good prediction for the ball's travel, but not an exact prediction. If we repeat the experiment many times, we can "average out" the fluctuations, and our measured average will match the prediction from Newton's law more closely—but never perfectly.

In real applications, functions are essential but imperfect abstractions. An engineer who designs a bridge using only idealized functional relationships—without allowing margin for real-world "noise" such as wind gusts, temperature changes, material imperfections, or earth movement—may experience catastrophic failure. The infamous Tacoma Narrows Bridge collapse of 1940 resulted partly from unexpected aerodynamic effects that the design equations hadn't accounted for.

The art of applied science lies in combining function-based abstract equations with probabilistic and stochastic variation. Scientists test functional models against real data, measure how much outcomes deviate from predictions, and refine their models accordingly. This interplay between idealized functions and messy reality sits at the heart of how we understand and engineer the world around us.

On a deeper level, quantum mechanics tells us that at a fine enough scale, deterministic laws like $F = ma$ or $E = IR$ cannot be exact. But for everyday engineering and most of science, the deterministic model works extraordinarily well.

Functions vs. Relations

Set theory is a broad topic, important in itself as a framework for mathematics and science, and as a foundation for the study of logic. Here, however, our focus is on sets as they apply in mathematics, specifically algebra, looking at set language as it applies to numbers and variables.

Any relation or function is determined by a rule for how elements in the domain are mapped to elements in the range. Functions are more restrictive than relations. With functions, a single element of $A$ is mapped to a single element of $B$. With relations, a single element of $A$ may map to more than one element of $B$.

Functions vs. Relations

A relation connects inputs to outputs, but allows one input to map to multiple outputs. The equation $x^2 + y^2 = 25$ describes a relation (a circle)—for $x = 3$, both $y = 4$ and $y = -4$ satisfy the equation.

A function is a special kind of relation where each input has exactly one output. This constraint is precisely what gives functions their power.

The square root symbol illustrates this distinction. The relation "numbers whose square is 9" includes both 3 and −3. But the function $\sqrt{x}$ is defined to return only the non-negative root. We make this choice specifically to ensure $\sqrt{x}$ is a proper function—deterministic and usable.

17.7.2 Functions Between Any Sets

Here's a crucial insight: the domain and codomain of a function don't have to be numbers. Functions can map between any kinds of objects, as long as each input produces exactly one output.

Examples of Non-Numerical Functions

Student records. Domain: Student ID numbers. Codomain: Student records. The function takes ID 12345 and returns {name: "Alice", major: "CS", GPA: 3.7}. Each ID maps to exactly one student record.

Biological mother. Domain: People. Codomain: People. Every person has exactly one biological mother. This mapping is a function. (Note: the reverse mapping—mother to children—is NOT a function, since a mother can have multiple children.)

Fingerprints. Domain: People. Codomain: Fingerprint patterns. Each person has a unique fingerprint pattern. This one-to-one correspondence is why fingerprints are used for identification.

Musical pitch. Domain: Musical note names in standard tuning. Codomain: Frequencies in Hertz. The note A4 (A above middle C) maps to 440 Hz. Middle C (C4) maps to approximately 261.6 Hz. Each note name corresponds to exactly one frequency.

ASCII encoding. Domain: ASCII codes (0–127). Codomain: Characters. The code 65 maps to 'A', 66 maps to 'B', 97 maps to 'a'. Each code maps to exactly one character. (This is how computers store text internally.)

Book titles. Domain: Novels. Codomain: Titles. Each novel has exactly one title. 1984 maps to "Nineteen Eighty-Four." (Note: different novels CAN share a title, so this function is not one-to-one, but it's still a function.)

Newton's Second Law as a function. For a fixed mass $m$, the function $F(a) = ma$ maps acceleration to force. Given any acceleration, there is exactly one corresponding force. Similarly, with fixed mass, $a(F) = F/m$ maps force to acceleration.

The Power of Abstraction

Functions describe any deterministic transformation process. The same mathematical concepts—domain, range, composition, inverse—apply whether we're working with numbers, text, biological relationships, or abstract structures. This is what makes function theory so broadly applicable across mathematics, computer science, and engineering.

17.7.3 Composition: Building Pipelines

A key property of functions, of fundamental importance in both mathematics and science, is composability. Just as in writing we can develop a thought by composing sentences that build upon previous sentences, in mathematics we can compose functions, where the output of one function becomes the input to another.

Another way to say this: the range of the first function becomes part of the domain of the second.

Function Composition

If $f$ and $g$ are functions, the composition $g \circ f$ (read "g composed with f" or "g of f") means: first apply $f$, then apply $g$ to the result.

$(g \circ f)(x) = g(f(x))$

For example, if $y = x^2$ and $z = 2y$, then $z = 2x^2$. The output of the first function ($y$) becomes the input to the second. Often a complex transformation can be broken down into understandable steps this way.

A Real-World Pipeline: Amplifying Sound

A good example is amplifying a voice for recording. When you speak into a microphone:

  1. Microphone: The microphone diaphragm converts air pressure variations $P$ into a tiny electrical voltage $v$. We can write this as a function: $v = f(P)$.
  2. Amplifier: This voltage is fed to an amplifier, which increases it from millivolts to a stronger signal (often volts): $w = g(v)$.
  3. ADC (Analog-to-Digital Converter): To store the signal in a computer, an ADC converts the amplified voltage to digital form as a series of time-sampled values: $D = h(w)$.

Altogether, from your voice to the sampled digital signal, we have: $D = h(g(f(P)))$.

Figure 17.4: Voice recording as a composition of functions. Each stage transforms its input deterministically, and the composition of all three gives the complete transformation from sound to digital data.

Not only does this decomposition make the entire transformation more understandable, but each step in the composition can be considered separately. Upgrading the microphone might improve the recording quality: this is a modification of the function $f$. Or we might want to improve the amplifier, changing $g$ without affecting $f$ or $h$. The modular structure lets us reason about each piece independently.

A Mathematical Example

Let $f(x) = x + 2$ (add 2) and $g(x) = 3x$ (triple).

Computing $g(f(x))$: First apply $f$, then $g$.

$g(f(x)) = g(x + 2) = 3(x + 2) = 3x + 6$

Computing $f(g(x))$: First apply $g$, then $f$.

$f(g(x)) = f(3x) = 3x + 2$

Notice: $g(f(x)) = 3x + 6$ but $f(g(x)) = 3x + 2$. Order matters! Adding 2 then tripling is not the same as tripling then adding 2.

Why Composition Matters

Complex systems are built from simple parts. Each function does one thing; composition chains them together. This is the foundation of:

• Modular programming: Functions that call other functions
• Data processing pipelines: Transform → filter → aggregate
• The calculus chain rule: How to differentiate composed functions

The determinism of functions (same input → same output) is what makes composition work. If individual functions were unpredictable, chaining them would compound the chaos.

17.7.4 Inverse Functions: Undoing Transformations

A key property of many functions is invertibility. If a function transforms inputs to outputs, can we "undo" it—go from outputs back to inputs? Sometimes yes, sometimes no.

We learned in Section 17.1 that if no two points in the domain of a function map to the same point in the range, the function is called one-to-one (or injective). One-to-one functions are invertible.

Physical Law Examples

In Ohm's Law, if the resistance $R$ is fixed, not only does the voltage equal $IR$, but we expect that by measuring the voltage, we can find the current:

$E = IR$    can be inverted to give    $I = \dfrac{E}{R}$

With Newton's Second Law, $F = ma$ allows us to calculate the force required to achieve a desired acceleration for a given mass. But this law can be inverted to give:

$a = \dfrac{F}{m}$

This allows us to calculate the acceleration of a given mass if we know the applied force. The invertibility of these functions is what makes them so useful: we can go in either direction.

When Inverses Exist

Consider $f(x) = 2x$ (doubling). If we know the output is 14, what was the input? There's exactly one answer: 7. We can always recover the input by halving. The inverse function is $f^{-1}(x) = \frac{x}{2}$.

Now consider $g(x) = x^2$ (squaring). If the output is 9, what was the input? It could have been 3 or −3—both square to 9. We can't uniquely recover the input, so $g$ has no inverse on all real numbers.

Inverse Function

A function $f$ has an inverse $f^{-1}$ if there exists a function that "undoes" $f$:

$f^{-1}(f(x)) = x$ for all $x$ in the domain of $f$
$f(f^{-1}(y)) = y$ for all $y$ in the range of $f$

Requirement: $f$ must be one-to-one—different inputs must give different outputs. If two inputs share an output, you can't tell which one to go back to.

More Examples

$f(x) = 2x$ has inverse $f^{-1}(x) = \frac{x}{2}$. (Doubling ↔ halving)

$f(x) = x + 5$ has inverse $f^{-1}(x) = x - 5$. (Adding 5 ↔ subtracting 5)

$f(x) = x^2$ does NOT have an inverse on all real numbers (fails one-to-one). But if we restrict to $x \geq 0$, then $f^{-1}(x) = \sqrt{x}$ works.

$f(x) = e^x$ and $g(x) = \ln(x)$ are inverses of each other. This is why logarithms "undo" exponentiation: $\ln(e^x) = x$ and $e^{\ln(x)} = x$.

Finding an Inverse Algebraically

To find the inverse of $f(x) = 3x - 7$:

  1. Write $y = 3x - 7$
  2. Solve for $x$:   $y + 7 = 3x$  →  $x = \frac{y + 7}{3}$
  3. Swap $x$ and $y$:   $f^{-1}(x) = \frac{x + 7}{3}$

Check: $f(f^{-1}(x)) = f\left(\frac{x+7}{3}\right) = 3 \cdot \frac{x+7}{3} - 7 = (x + 7) - 7 = x$ ✓

Graphical Interpretation

The graph of $f^{-1}$ is the reflection of the graph of $f$ across the line $y = x$. Points $(a, b)$ on the graph of $f$ correspond to points $(b, a)$ on the graph of $f^{-1}$.

Example 1: Coordinate Transformations

In physics and engineering, the same physical situation can be described in different coordinate systems. A problem that's difficult in Cartesian coordinates $(x, y)$ might become simple in polar coordinates $(r, \theta)$.

Consider computing the area inside a circle. In Cartesian coordinates, this requires dealing with the equation $x^2 + y^2 = R^2$ and the resulting square roots. In polar coordinates, the circle is simply $r = R$ (constant radius), and the area calculation becomes straightforward.

The physics is unchanged; only the mathematical representation differs. By choosing the right coordinate system, we make the problem easier.

Example 2: Substitution in Algebra

Suppose we need to solve an equation like $(2x + 1)^2 - 5(2x + 1) + 6 = 0$. This looks complicated, but notice that $2x + 1$ appears repeatedly. Let's substitute $u = 2x + 1$:

Original: $(2x + 1)^2 - 5(2x + 1) + 6 = 0$
Substituting: $u^2 - 5u + 6 = 0$

Now we have a simple quadratic! Factoring: $(u - 2)(u - 3) = 0$, so $u = 2$ or $u = 3$.

Transform back: If $u = 2x + 1 = 2$, then $x = \frac{1}{2}$. If $u = 2x + 1 = 3$, then $x = 1$.

The substitution $u = 2x + 1$ transformed a messy problem into a clean one. We solved in the "u-domain," then transformed back.

Example 3: Digital Everything

Every digital system uses this pattern. Computers don't work with images, sounds, or text directly. Instead:

  1. Transform (encode): Convert images/sounds/text into numbers
  2. Process: Manipulate the numbers
  3. Transform back (decode): Convert numbers back to human-meaningful form

When you edit a photo, your software transforms pixels to numbers, applies mathematical operations, and transforms back to a visible image. When you make a phone call, your voice is transformed to numbers, transmitted, and transformed back to sound. The entire digital world is built on this transform → process → inverse-transform pattern.

The Pattern Appears Everywhere

Mathematics: Change of variables, substitution, coordinate systems
Physics: Reference frames, Fourier analysis, Laplace transforms
Computer Science: Data representations, encodings, compression
Engineering: Mathematical models of physical systems, signal processing

The ability to move between representations—finding the one where your problem becomes tractable—is one of the most valuable skills in technical work.

17.7.6 The Big Picture: From Numbers to Transformations

We've covered a lot of ground. Let's step back and see the larger significance.

A Conceptual Shift in Mathematics

For centuries, mathematics was primarily about finding specific numbers—solving for $x$, computing areas, calculating distances. The function concept shifted attention from individual values to processes of transformation.

Instead of asking "What is $x$?", we began asking "How does this system behave? How do outputs change as inputs change?"

This shift enabled:

  • Calculus: The study of how functions change (derivatives) and accumulate (integrals)
  • Modern physics: Laws expressed as relationships between quantities, not specific values
  • Computer science: Programs as functions transforming inputs to outputs
  • Abstract mathematics: Studying structures through the mappings between them

Connection to a Recurring Theme

Throughout this curriculum, we've seen a pattern: mathematics evolves from asking "what ARE these objects?" to asking "how do these objects BEHAVE?"

Ancient mathematicians asked: "What ARE negative numbers? Do they really exist? How can you have less than nothing?"

The modern view: Negative numbers are defined by how they behave under operations. We don't worry about what they "really are"—we define them by their properties.

Functions followed the same path. Early mathematicians asked "What IS a function?" and answered "a formula." But over centuries, the definition expanded as problems revealed that "formula" was too narrow. The modern definition—a deterministic mapping between sets—captures the essence without limiting the form.

Structural Thinking

This shift from "what is it?" to "how does it behave?" is called structural thinking. Objects are defined not by what they're "made of" but by their properties and relationships.

It's one of the most powerful conceptual tools in mathematics, and it underlies virtually all advanced mathematical work. Functions, defined as "deterministic mappings" rather than "formulas," are a prime example of this structural approach.

The Long Road to a Definition: 250 Years of the Function Concept

The modern definition of a function—a deterministic mapping between sets—seems natural now. But it took mathematicians over 250 years to arrive at it. Each expansion of the definition wasn't arbitrary; it was forced by mathematics and physics revealing that the old definition was too narrow.

Functional Thinking Before Europe

While the explicit concept of function emerged in 17th-century Europe, functional relationships—the understanding that one quantity depends systematically on another—appeared across cultures long before.

Babylonian mathematicians (c. 2000 BCE) created extensive clay tablets listing ordered pairs: inputs and their corresponding squares, cubes, and reciprocals. These were effectively function tables, though the Babylonians wouldn't have thought of them that way.

Indian astronomers (5th century CE onward) compiled trigonometric tables in works like the Surya Siddhanta, tabulating sine values for systematic angle increments.

Islamic mathematicians built on both traditions. Al-Khwarizmi (9th century) created astronomical tables linking time to planetary positions, and Sharaf al-Din al-Tusi (12th century) analyzed cubic equations in ways that showed deep understanding of how variables depend on one another.

The distinction is between using functional relationships (which many cultures did) and conceptualizing functions as objects of study (which happened in Europe as calculus developed). The formal concept required both the problem—understanding rates of change—and the algebraic notation to express it.

Phase 1: Functions as Formulas (1673–1750)

The word "function" entered mathematics through Gottfried Wilhelm Leibniz. In 1673, he used the Latin functio in a letter, but only to describe geometric quantities associated with a curve—lengths of tangents, coordinates, and the like. The curve itself was primary; functions were secondary descriptors.

The first formal definition came from Johann Bernoulli in 1718:

"A function of a variable quantity is a quantity composed in any way whatsoever from this variable quantity and constants."

Translation: a function is a formula. If you could write it down using algebraic operations, it was a function. If you couldn't write a formula for it, it wasn't a function.

In 1734, Leonhard Euler introduced the notation $f(x)$, which we still use today. His influential 1748 textbook Introductio in Analysin Infinitorum declared that "a function of a variable quantity is an analytic expression composed in any way whatsoever of the variable quantity and numbers or constant quantities." Again: function = formula.

Euler's Transformation of Trigonometry

Euler did something remarkable in his 1748 work: he transformed trigonometric quantities from geometric objects (line segments in circles) into functions. Before Euler, $\sin\theta$ was defined as a specific line segment in a circle of radius 1. After Euler, $\sin(x)$ was a function that could be evaluated at any value, analyzed algebraically, and combined with other functions. This shift—from geometric construction to functional relationship—was a major step toward abstraction.

Phase 2: The Vibrating String Controversy (1740s–1750s)

Physics forced mathematicians to reconsider. Jean le Rond d'Alembert, Euler, and Daniel Bernoulli studied the vibrating string problem—what we now call the wave equation. The question: what shapes could a string have at the starting moment?

Euler began to allow what he called "discontinuous" functions—shapes that couldn't be described by a single formula. Consider a plucked string: two straight line segments meeting at a point. This shape is perfectly reasonable physically, but it can't be written as one formula. You'd need something like:

$y = \begin{cases} \frac{x}{a} & \text{if } 0 \leq x \leq a \\ \frac{L-x}{L-a} & \text{if } a < x \leq L \end{cases}$

Was this a "function"? The physics said yes—it described a real string shape. The definition said no—it wasn't a single formula. This controversy simmered for decades.

Phase 3: Fourier Breaks the Mold (1807–1822)

Joseph Fourier, studying heat conduction, made a revolutionary claim: any function—even discontinuous ones, even arbitrary shapes—could be represented as an infinite sum of sines and cosines (what we now call a Fourier series).

This was controversial. Joseph-Louis Lagrange rejected it. But the implications were profound: if many different-looking formulas could represent the same function, then a function is not the same as its formula.

Think about it: the same input-output relationship could be written as a polynomial, a Fourier series, or a piecewise formula. The formulas looked completely different, but the function—the actual correspondence between inputs and outputs—was the same. This meant the definition needed to focus on the correspondence itself, not on how it was written down.

Phase 4: Dirichlet's Revolution (1837)

Peter Gustav Lejeune Dirichlet resolved the confusion by separating the concept of "function" from its representation. In his 1837 paper on Fourier series, he gave what became the foundation of the modern definition:

"If a variable $y$ is related to a variable $x$ in such a way that whenever a numerical value is assigned to $x$, there is a rule according to which a unique value of $y$ is determined, then $y$ is called a function of $x$."

The key insight: no formula is required. The "rule" can be any unambiguous assignment. To drive home the point, Dirichlet gave a shocking example—a function with no possible formula:

The Dirichlet Function

$$D(x) = \begin{cases} 1 & \text{if } x \text{ is rational} \\ 0 & \text{if } x \text{ is irrational} \end{cases}$$ This function is perfectly well-defined: every input has exactly one output. But it cannot be written as any ordinary formula, and its graph cannot be drawn—it's discontinuous at every point! Between any two rationals there are irrationals (giving 0), and between any two irrationals there are rationals (giving 1).

The Dirichlet function demonstrated that "function" was a broader concept than "formula." A function is defined by what it does (assigns exactly one output to each input), not by how it's written.

Phase 5: Set Theory and Full Abstraction (1880s–1939)

As set theory developed through the work of Georg Cantor and Richard Dedekind, mathematicians realized functions could be defined purely in terms of sets. A function is a set of ordered pairs $(x, y)$ where each input $x$ appears exactly once.

In 1939, the Bourbaki group (a collective of French mathematicians writing under a pseudonym) formalized this:

A function $f: A \to B$ is a subset of $A \times B$ satisfying the condition that for each $a \in A$, there exists exactly one $b \in B$ such that $(a, b)$ is in the subset.

Now functions could map between any sets—not just numbers. The domain could be geometric shapes, character strings, abstract mathematical objects, or computer data structures. This is the definition we use today.

Why This Matters

Each expansion of the definition wasn't mathematicians being pedantic—it was mathematics and physics revealing that the old definition was too restrictive. The problems came first; the expanded definitions followed.

The modern definition is powerful precisely because it's abstract: it captures the essence of what a function does (deterministic input-output correspondence) without limiting what kinds of objects can be inputs and outputs, or how the correspondence must be expressed.

The Pattern: From "What Is It?" to "How Does It Behave?"

The evolution of the function concept exemplifies our recurring theme. Early mathematicians asked "What IS a function?" and answered "a formula." But over 250 years, the question shifted to "How does a function BEHAVE?"—and the answer became "it deterministically assigns outputs to inputs."

This same pattern appears throughout mathematics: negative numbers, irrational numbers, complex numbers, and functions all followed paths from concrete representations to abstract behavioral definitions. The abstraction isn't a retreat from reality—it's a recognition of what truly matters about these objects.

A Closing Thought

A function is a bridge between mathematical worlds. The power of mathematics lies not just in the worlds themselves, but in the bridges we build between them. When you transform a problem from one domain to another, solve it, and transform back, you're using functions as tools for thought—exactly as mathematicians, scientists, and engineers do every day.

You now have the vocabulary and concepts to recognize functions everywhere: in equations you solve, in graphs you analyze, in computer programs you write, in physical laws you study. They're not just notation—they're one of mathematics' most fundamental ideas.
