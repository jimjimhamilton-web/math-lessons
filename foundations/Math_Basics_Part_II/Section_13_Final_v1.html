Section 13: Systems of Linear Equations

So far, we've worked with single equations containing one or two variables. But many real-world problems involve multiple conditions that must all be satisfied at once. A business needs to meet both a budget constraint and a production target. A diet plan requires hitting protein goals while staying under a calorie limit. Two cars traveling toward each other will meet when they've covered the total distance between them—but when and where?

These situations lead us to systems of equations: two or more equations that must be solved together. The solution must work for all the equations simultaneously, not just one at a time.

13.1 What Systems Mean

System of Equations

A system of equations is a set of two or more equations with the same variables. A solution to the system is a set of values that makes all the equations true simultaneously.

Systems can involve many types of equations—quadratic, exponential, trigonometric, and others. In Section 12, we began our study of equations by focusing on linear equations, where variables appear only to the first power: there are no exponents like $x^2$ or $y^3$, no square roots, and no more complicated functions of the variables. In this section, we continue that focus by studying systems of two linear equations. We'll see what solutions that satisfy both equations look like, and learn systematic methods for finding them.

Consider this system of two linear equations:

$$x + y = 5$$ $$x - y = 1$$

A solution must satisfy both equations. Let's test a few candidates:

  • Try $x = 2$, $y = 3$: First equation: $2 + 3 = 5$ ✓. Second equation: $2 - 3 = -1 \neq 1$ ✗. This is not a solution.
  • Try $x = 3$, $y = 2$: First equation: $3 + 2 = 5$ ✓. Second equation: $3 - 2 = 1$ ✓. This is a solution.

The ordered pair $(3, 2)$ is the solution to this system. It's the only pair of values that works in both equations.

The Geometric Picture

In Section 12, we learned that a linear equation in two variables produces a straight line when graphed. Each point on the line represents a solution to that equation. So what happens when we graph two linear equations?

Each equation gives us a line. A solution to the system must lie on both lines—that is, it must be a point where the lines intersect. This geometric insight gives us three possibilities:

Fig. 13.1 — The Three Cases for Systems of Linear Equations
(a) One Solution
(b) No Solution
(c) Infinitely Many Solutions
(a) Lines with different slopes intersect at exactly one point. (b) Parallel lines (same slope, different intercepts) never intersect. (c) The same line (equations are equivalent) has infinitely many common points.

Three Cases for Linear Systems

A system of two linear equations in two variables has exactly one of these outcomes:

  1. One solution: The lines intersect at exactly one point. The system is consistent and independent.
  2. No solution: The lines are parallel (same slope, different $y$-intercepts). The system is inconsistent.
  3. Infinitely many solutions: The lines are identical (the equations are equivalent). The system is consistent and dependent.

Recall from Section 12.8 that two lines with different slopes must intersect somewhere. This means: if two linear equations have different slopes, the system is guaranteed to have exactly one solution. Parallel lines have the same slope but different $y$-intercepts—they run alongside each other forever without meeting.

Example: Identifying the Number of Solutions

Without solving, determine how many solutions each system has.

(a) $y = 2x + 1$ and $y = -x + 4$

The slopes are $2$ and $-1$—different. The lines must intersect.
Answer: One solution.

(b) $y = 3x - 2$ and $y = 3x + 5$

Both lines have slope $3$, but different $y$-intercepts ($-2$ and $5$). They're parallel.
Answer: No solution.

(c) $2x + 4y = 8$ and $x + 2y = 4$

Let's rewrite both in slope-intercept form. First equation: $4y = -2x + 8$, so $y = -\frac{1}{2}x + 2$. Second equation: $2y = -x + 4$, so $y = -\frac{1}{2}x + 2$. These are the same equation!
Answer: Infinitely many solutions.

13.2 Solving by Graphing

The most intuitive way to solve a system is to graph both equations and find where the lines cross. This method gives us a visual understanding of what we're looking for.

Procedure: Solving by Graphing

  1. Graph each equation on the same coordinate plane.
  2. Identify the point of intersection (if any).
  3. Read the coordinates of the intersection point.
  4. Check by substituting into both original equations.

Example: Solving a System by Graphing

Solve the system by graphing:

$$y = 2x - 1$$

$$y = -x + 5$$

Step 1: Graph each line.

First equation: $y = 2x - 1$ has slope $2$ and $y$-intercept $-1$. Start at $(0, -1)$ and use "rise 2, run 1" to plot additional points.

Second equation: $y = -x + 5$ has slope $-1$ and $y$-intercept $5$. Start at $(0, 5)$ and use "rise $-1$, run 1" (or equivalently, "down 1, right 1").

Fig. 13.2 — Solving by Graphing
The lines $y = 2x - 1$ and $y = -x + 5$ intersect at $(2, 3)$.

Step 2: Find the intersection.

The lines appear to cross at $(2, 3)$.

Step 3: Check in both equations.

First equation: $y = 2x - 1 \Rightarrow 3 = 2(2) - 1 = 4 - 1 = 3$ ✓

Second equation: $y = -x + 5 \Rightarrow 3 = -(2) + 5 = -2 + 5 = 3$ ✓

Answer: $(2, 3)$

Strengths and Limitations of Graphing

Graphing is valuable because it shows us what's happening. We can see whether lines intersect, run parallel, or coincide. We can estimate where the solution lies even before doing any algebra.

But graphing has a significant limitation: precision depends on how carefully we draw. If the solution is $(2, 3)$, we can read it exactly. But what if the solution is $\left(\frac{7}{3}, \frac{11}{5}\right)$? We'd see the intersection is "somewhere around $(2.3, 2.2)$" but couldn't determine the exact values from a graph.

If you need an answer to several digits of precision—say, two or more significant figures—graphing alone won't get you there. A carefully drawn graph might tell you the solution is "approximately $(2.3, 2.2)$," but is it $(2.33, 2.20)$ or $(2.35, 2.18)$? You can't tell by looking. When precision matters, graphing helps you understand the problem, but algebraic methods are needed to find the solution to the desired accuracy.

When Graphing Helps

  • Visualization: Graphing shows whether a solution exists and roughly where it is.
  • Intuition: Seeing the lines helps you understand the problem and catch errors. If your algebraic answer is $(10, -15)$ but the graph clearly shows intersection in the first quadrant, something went wrong.
  • Estimation: A quick sketch tells you "the answer is around $(3, 4)$"—useful for checking reasonableness or choosing good starting values for iterative methods.
  • Guiding your approach: More broadly, graphical and geometric thinking are powerful tools throughout mathematics. Visualizing a problem often reveals structure that suggests the right algebraic approach. Even when you need an exact numerical answer, a picture can show you how to find it.

For exact answers, especially with non-integer solutions, we need algebraic methods—which we develop in the next two sections.

13.3 Solving by Substitution

We've seen that two non-parallel lines in the plane must intersect at exactly one point—the solution to the system of equations those lines represent. Graphing can give us an estimate of that solution, but we usually need more accuracy.

In this section and the next, we'll learn two systematic algebraic methods for finding exact solutions to systems of linear equations: the substitution method (this section) and the elimination method (Section 13.4).

The substitution method uses one equation to express one variable in terms of the other, then substitutes that expression into the second equation. This reduces a system of two equations in two variables to a single equation in one variable—which we already know how to solve.

Procedure: Solving by Substitution

  1. Solve one equation for one variable (choose whichever is easiest).
  2. Substitute that expression into the other equation.
  3. Solve the resulting equation for the remaining variable.
  4. Substitute back to find the other variable.
  5. Check in both original equations.

Don't Stop Halfway!

A common mistake is to find the value of one variable and think you're done. Remember: a solution to a system requires values for both variables. After Step 3 gives you one variable, you must continue to Step 4 to find the other.

Example 1: Variable Already Isolated

Solve the system:

$$y = 3x - 4$$

$$2x + y = 6$$

Step 1: The first equation already has $y$ isolated: $y = 3x - 4$.

Step 2: Substitute $3x - 4$ for $y$ in the second equation:

$$2x + (3x - 4) = 6$$

Step 3: Solve for $x$:

$$2x + 3x - 4 = 6$$

$$5x - 4 = 6$$

$$5x = 10$$

$$x = 2$$

Step 4: Substitute $x = 2$ back into $y = 3x - 4$:

$$y = 3(2) - 4 = 6 - 4 = 2$$

Step 5: Check in both original equations:

  • First equation: $y = 3x - 4 \Rightarrow 2 = 3(2) - 4 = 2$ ✓
  • Second equation: $2x + y = 6 \Rightarrow 2(2) + 2 = 4 + 2 = 6$ ✓

Answer: $(2, 2)$

Example 2: Isolating a Variable First

Solve the system:

$$x + 3y = 7$$

$$2x - y = 0$$

Step 1: Choose a variable to isolate. Looking at the second equation, solving for $y$ is easy (coefficient is just $-1$):

$$2x - y = 0$$

$$-y = -2x$$

$$y = 2x$$

Step 2: Substitute $y = 2x$ into the first equation:

$$x + 3(2x) = 7$$

Step 3: Solve for $x$:

$$x + 6x = 7$$

$$7x = 7$$

$$x = 1$$

Step 4: Find $y$:

$$y = 2x = 2(1) = 2$$

Step 5: Check:

  • First equation: $x + 3y = 1 + 3(2) = 1 + 6 = 7$ ✓
  • Second equation: $2x - y = 2(1) - 2 = 0$ ✓

Answer: $(1, 2)$

Example 3: Fractional Coefficients

Solve the system:

$$3x - 2y = 12$$

$$x + 4y = -2$$

Step 1: The second equation has $x$ with coefficient $1$—easy to isolate:

$$x = -2 - 4y$$

Step 2: Substitute into the first equation:

$$3(-2 - 4y) - 2y = 12$$

Step 3: Solve for $y$:

$$-6 - 12y - 2y = 12$$

$$-6 - 14y = 12$$

$$-14y = 18$$

$$y = \frac{18}{-14} = -\frac{9}{7}$$

Step 4: Find $x$:

$$x = -2 - 4\left(-\frac{9}{7}\right) = -2 + \frac{36}{7} = \frac{-14 + 36}{7} = \frac{22}{7}$$

Step 5: Check (using fractions carefully):

  • First equation: $3\left(\frac{22}{7}\right) - 2\left(-\frac{9}{7}\right) = \frac{66}{7} + \frac{18}{7} = \frac{84}{7} = 12$ ✓
  • Second equation: $\frac{22}{7} + 4\left(-\frac{9}{7}\right) = \frac{22}{7} - \frac{36}{7} = \frac{-14}{7} = -2$ ✓

Answer: $\left(\frac{22}{7}, -\frac{9}{7}\right)$ or approximately $(3.14, -1.29)$

Example 4: Decimal Coefficients (Calculator Recommended)

Solve the system:

$$1.5x + 2y = 9.3$$

$$y = 0.8x + 1.1$$

Step 1: The second equation already has $y$ isolated.

Step 2: Substitute into the first equation:

$$1.5x + 2(0.8x + 1.1) = 9.3$$

Step 3: Solve for $x$:

$$1.5x + 1.6x + 2.2 = 9.3$$

$$3.1x + 2.2 = 9.3$$

$$3.1x = 7.1$$

$$x = \frac{7.1}{3.1} \approx 2.29$$

Step 4: Find $y$:

$$y = 0.8(2.29) + 1.1 \approx 1.83 + 1.1 = 2.93$$

Step 5: Check (using the more precise value $x = 7.1/3.1$):

For checking, we can use $x \approx 2.2903$ and $y \approx 2.9323$:

  • First equation: $1.5(2.2903) + 2(2.9323) \approx 3.44 + 5.86 = 9.30$ ✓
  • Second equation: $0.8(2.2903) + 1.1 \approx 1.83 + 1.1 = 2.93$ ✓

Answer: $(2.29, 2.93)$ (to two decimal places)

Note: With decimal coefficients, small rounding differences may accumulate. For higher precision, keep more decimal places during calculations or use exact fractions: $x = \frac{71}{31}$ and $y = \frac{91}{31}$.

Choosing Which Variable to Isolate

Look for a variable with coefficient $1$ or $-1$—it isolates without introducing fractions. In Example 3, we chose to isolate $x$ in the second equation because its coefficient was $1$. If we had isolated $y$ from the first equation, we'd get $y = \frac{3x - 12}{2}$—messier, though it would still work.

There's no "wrong" choice—just easier and harder paths to the same answer.

Practice Problems: Substitution

Try These (Solutions Below)

1. Solve by substitution: $y = 2x + 1$ and $3x + y = 11$
2. Solve by substitution: $x - 2y = 4$ and $3x + y = 5$
3. Solve by substitution: $2x + 5y = 1$ and $x + 3y = -1$
4. (Calculator) Solve by substitution: $y = 1.2x - 0.5$ and $2.5x + 3y = 14.9$

Solutions

Problem 1: Substitute $y = 2x + 1$ into $3x + y = 11$:

$3x + (2x + 1) = 11 \Rightarrow 5x + 1 = 11 \Rightarrow 5x = 10 \Rightarrow x = 2$

Then $y = 2(2) + 1 = 5$.

Answer: $(2, 5)$

Problem 2: From the first equation, $x = 2y + 4$. Substitute into $3x + y = 5$:

$3(2y + 4) + y = 5 \Rightarrow 6y + 12 + y = 5 \Rightarrow 7y = -7 \Rightarrow y = -1$

Then $x = 2(-1) + 4 = 2$.

Answer: $(2, -1)$

Problem 3: From the second equation, $x = -1 - 3y$. Substitute into $2x + 5y = 1$:

$2(-1 - 3y) + 5y = 1 \Rightarrow -2 - 6y + 5y = 1 \Rightarrow -2 - y = 1 \Rightarrow y = -3$

Then $x = -1 - 3(-3) = -1 + 9 = 8$.

Answer: $(8, -3)$

Problem 4: Substitute $y = 1.2x - 0.5$ into $2.5x + 3y = 14.9$:

$2.5x + 3(1.2x - 0.5) = 14.9$

$2.5x + 3.6x - 1.5 = 14.9$

$6.1x = 16.4$

$x = 16.4 \div 6.1 \approx 2.69$

Then $y = 1.2(2.69) - 0.5 \approx 3.23 - 0.5 = 2.73$.

Check: $2.5(2.69) + 3(2.73) = 6.725 + 8.19 = 14.915 \approx 14.9$ ✓

Answer: $(2.69, 2.73)$ (to two decimal places)

13.4 Solving by Elimination

The elimination method (also called the addition method) takes a different approach: instead of substituting one equation into another, we add or subtract the equations to eliminate one variable entirely.

The key insight is that we can add equations together. If $A = B$ and $C = D$, then $A + C = B + D$. When the coefficients of one variable are opposites (like $3y$ and $-3y$), adding the equations makes that variable disappear.

Procedure: Solving by Elimination

  1. Arrange both equations in standard form ($Ax + By = C$), with like terms aligned.
  2. If necessary, multiply one or both equations so that the coefficients of one variable are opposites.
  3. Add the equations to eliminate one variable.
  4. Solve the resulting equation.
  5. Substitute back to find the other variable.
  6. Check in both original equations.

Example 1: Direct Elimination (Coefficients Already Opposite)

Solve the system:

$$2x + 3y = 13$$

$$2x - 3y = -1$$

Step 1: The equations are already in standard form with terms aligned.

Step 2: Notice that the $y$-coefficients are already opposites: $+3y$ and $-3y$. No multiplication needed.

Step 3: Add the equations:

$$\begin{array}{rcrcr} 2x & + & 3y & = & 13 \\ 2x & - & 3y & = & -1 \\ \hline 4x & + & 0 & = & 12 \end{array}$$

Step 4: Solve for $x$:

$$4x = 12$$

$$x = 3$$

Step 5: Substitute $x = 3$ into either original equation. Using the first:

$$2(3) + 3y = 13$$

$$6 + 3y = 13$$

$$3y = 7$$

$$y = \frac{7}{3}$$

Step 6: Check in both original equations:

  • First: $2(3) + 3\left(\frac{7}{3}\right) = 6 + 7 = 13$ ✓
  • Second: $2(3) - 3\left(\frac{7}{3}\right) = 6 - 7 = -1$ ✓

Answer: $\left(3, \frac{7}{3}\right)$

Example 2: Multiplying One Equation

Solve the system:

$$3x + 2y = 11$$

$$x - y = 2$$

Step 1: Equations are in standard form.

Step 2: We need opposite coefficients for one variable. Looking at $y$: the first equation has $+2y$ and the second has $-y$. If we multiply the second equation by $2$, we'll have $-2y$, which is the opposite of $+2y$.

Multiply the second equation by $2$:

$$2(x - y) = 2(2)$$

$$2x - 2y = 4$$

Step 3: Add the equations:

$$\begin{array}{rcrcr} 3x & + & 2y & = & 11 \\ 2x & - & 2y & = & 4 \\ \hline 5x & + & 0 & = & 15 \end{array}$$

Step 4: Solve for $x$:

$$5x = 15$$

$$x = 3$$

Step 5: Substitute into the (original) second equation:

$$3 - y = 2$$

$$y = 1$$

Step 6: Check:

  • First: $3(3) + 2(1) = 9 + 2 = 11$ ✓
  • Second: $3 - 1 = 2$ ✓

Answer: $(3, 1)$

Example 3: Multiplying Both Equations

Solve the system:

$$2x + 3y = 7$$

$$3x + 4y = 10$$

Step 1: Equations are in standard form.

Step 2: Neither variable has coefficients that are opposites or easy multiples. Let's eliminate $x$. The coefficients are $2$ and $3$. To get opposites, we can:

  • Multiply the first equation by $3$: gives $6x$
  • Multiply the second equation by $-2$: gives $-6x$

First equation $\times 3$: $\quad 6x + 9y = 21$

Second equation $\times (-2)$: $\quad -6x - 8y = -20$

Step 3: Add:

$$\begin{array}{rcrcr} 6x & + & 9y & = & 21 \\ -6x & - & 8y & = & -20 \\ \hline 0 & + & y & = & 1 \end{array}$$

Step 4: We get $y = 1$ directly.

Step 5: Substitute into the first original equation:

$$2x + 3(1) = 7$$

$$2x = 4$$

$$x = 2$$

Step 6: Check:

  • First: $2(2) + 3(1) = 4 + 3 = 7$ ✓
  • Second: $3(2) + 4(1) = 6 + 4 = 10$ ✓

Answer: $(2, 1)$

Example 4: Decimal Coefficients (Calculator Recommended)

Solve the system:

$$0.4x + 0.3y = 2.3$$

$$0.5x - 0.2y = 1.4$$

Step 1: Equations are in standard form. (We could multiply to clear decimals, but let's work with them directly.)

Step 2: To eliminate $y$, we need opposite coefficients. The $y$-coefficients are $0.3$ and $-0.2$. Multiply the first equation by $2$ and the second by $3$:

First equation $\times 2$: $\quad 0.8x + 0.6y = 4.6$

Second equation $\times 3$: $\quad 1.5x - 0.6y = 4.2$

Step 3: Add the equations:

$$\begin{array}{rcrcr} 0.8x & + & 0.6y & = & 4.6 \\ 1.5x & - & 0.6y & = & 4.2 \\ \hline 2.3x & + & 0 & = & 8.8 \end{array}$$

Step 4: Solve for $x$:

$$x = \frac{8.8}{2.3} \approx 3.83$$

Step 5: Substitute into the first original equation:

$$0.4(3.83) + 0.3y = 2.3$$

$$1.532 + 0.3y = 2.3$$

$$0.3y = 0.768$$

$$y \approx 2.56$$

Step 6: Check:

  • First: $0.4(3.83) + 0.3(2.56) = 1.53 + 0.77 = 2.30$ ✓
  • Second: $0.5(3.83) - 0.2(2.56) = 1.92 - 0.51 = 1.41 \approx 1.4$ ✓

Answer: $(3.83, 2.56)$ (to two decimal places)

Alternative approach: Multiply both equations by 10 first to clear decimals: $4x + 3y = 23$ and $5x - 2y = 14$. This often makes the arithmetic cleaner.

Choosing Multipliers

To eliminate a variable, you need its coefficients to be opposites. If the coefficients are $a$ and $b$, you can:

  • Multiply the first equation by $b$ and the second by $-a$, or
  • Multiply the first by $-b$ and the second by $a$

Either way, the coefficients become $ab$ and $-ab$, which cancel when you add.

Tip: Look for the least common multiple (LCM) of the coefficients to keep numbers small. In Example 3, the LCM of $2$ and $3$ is $6$.

Common Errors in Elimination

  • Forgetting to multiply the entire equation: When you multiply an equation by a number, every term (including the constant) must be multiplied.
  • Sign errors when adding: Pay careful attention to signs, especially when one equation has been multiplied by a negative number.
  • Using the modified equation to find the second variable: After elimination, substitute into an original equation, not a modified one. This reduces the chance of propagating an earlier error.
  • Stopping after finding one variable: After elimination gives you one variable's value, you must substitute back to find the other. The solution isn't complete until you have values for both variables.

3. Solve by elimination: $3x + 2y = 8$ and $2x + 5y = 9$

$2x = 10 \Rightarrow x = 5$

Problem 2: The $y$-coefficients are already opposites ($+3y$ and $-3y$). Add:

$6x = 18 \Rightarrow x = 3$

Substitute: $2(3) + 3y = 12 \Rightarrow 6 + 3y = 12 \Rightarrow y = 2$

Problem 3: Eliminate $x$: multiply first equation by $2$ and second by $-3$:

$6x + 4y = 16$

$-6x - 15y = -27$

$1.5x + 2.5y = 11$

$-1.5x + 4.5y = 15$

$0.5x - 5.57 = -5$

Substitution vs. Elimination: A Preview

Both methods always work, and both give the same answer. The choice often comes down to which makes the arithmetic simpler:

  • Substitution tends to be easiest when one equation is already solved for a variable, or when a variable has coefficient $1$ or $-1$.
  • Elimination tends to be easiest when the equations are in standard form and the coefficients line up nicely.

We'll compare the methods more systematically in Section 13.6, after we've seen some special cases.

13.5 Special Cases

In Section 13.1, we saw that a system of two linear equations can have exactly one solution (intersecting lines), no solution (parallel lines), or infinitely many solutions (the same line). When we solved systems in Sections 13.3 and 13.4, our examples all had exactly one solution. Now let's see what happens algebraically when we encounter the special cases.

No Solution: The Inconsistent System

When two lines are parallel, they never intersect, so there's no point that satisfies both equations. What does this look like when we try to solve algebraically?

Example 1: A System with No Solution

Solve the system:

$$2x + y = 5$$

$$4x + 2y = 3$$

Using elimination: Multiply the first equation by $-2$ to eliminate $x$:

$$-4x - 2y = -10$$

$$4x + 2y = 3$$

Add the equations:

$$0 = -7$$

This is a false statement—zero does not equal negative seven, no matter what values $x$ and $y$ have. This tells us the system has no solution.

Why did this happen? Let's look at the original equations more carefully. Rewrite both in slope-intercept form:

  • First equation: $y = -2x + 5$
  • Second equation: $2y = -4x + 3$, so $y = -2x + \frac{3}{2}$

Both lines have slope $-2$, but different $y$-intercepts ($5$ vs. $\frac{3}{2}$). They're parallel—they never meet.

Answer: No solution. The system is inconsistent.

Recognizing "No Solution"

When solving a system algebraically, if the variables cancel out and you're left with a false statement (like $0 = -7$ or $5 = 12$), the system has no solution.

Geometrically, this means the lines are parallel—same slope, different intercepts.

Infinitely Many Solutions: The Dependent System

When two equations represent the same line, every point on that line satisfies both equations. What does this look like algebraically?

Example 2: A System with Infinitely Many Solutions

Solve the system:

$$x - 2y = 4$$

$$3x - 6y = 12$$

Using elimination: Multiply the first equation by $-3$ to eliminate $x$:

$$-3x + 6y = -12$$

$$3x - 6y = 12$$

Add the equations:

$$0 = 0$$

This is a true statement—but it doesn't tell us what $x$ and $y$ are! This happens because the two equations are actually the same equation in disguise.

Check: The second equation $3x - 6y = 12$ is exactly $3$ times the first equation $x - 2y = 4$. They represent the same line.

Answer: Infinitely many solutions. Every point on the line $x - 2y = 4$ (or equivalently, $y = \frac{1}{2}x - 2$) is a solution. The system is dependent.

Recognizing "Infinitely Many Solutions"

When solving a system algebraically, if the variables cancel out and you're left with a true statement (like $0 = 0$ or $12 = 12$), the system has infinitely many solutions.

Geometrically, this means the two equations represent the same line—one equation is a multiple of the other.

Summary: What the Algebra Tells You

When solving leads to... The system has... Geometrically...
A unique value for each variable Exactly one solution Lines intersect at one point
A false statement (e.g., $0 = 5$) No solution (inconsistent) Lines are parallel
A true statement (e.g., $0 = 0$) Infinitely many solutions (dependent) Lines are identical

Interpreting Special Cases in Context

What do these special cases mean when the system comes from a real-world problem?

  • No solution often means the problem's constraints are contradictory—you're being asked to do something impossible. For example, "Find a mixture that weighs 10 pounds and costs 50 dollars" might have no solution if the available ingredients can't produce that combination.
  • Infinitely many solutions often means the problem is underdetermined—you have more freedom than you realized. For example, if two "different" budget constraints turn out to be the same constraint expressed differently, any point satisfying that constraint works.

13.6 Choosing a Method

We now have three methods for solving systems of linear equations: graphing, substitution, and elimination. All three represent the same answer (when a unique solution exists). If you don't need an answer accurate to many decimal places, a graphical solution may be all you need—though for simple problems, algebraic methods may actually be less work than drawing an accurate graph. A graphical solution can also give you better understanding of the problem than just obtaining a single point from algebra. If you need an accurate decimal or fractional answer, choose substitution or elimination. The choice ultimately comes down to what sort of understanding you need and what makes the work easiest for a particular problem.

Method Comparison

Method Advantages Disadvantages Best When...
Graphing Visual; shows relationship between equations; reveals special cases Imprecise for non-integer solutions; time-consuming to draw accurately You want to understand the problem visually; you need an estimate; checking reasonableness of algebraic answer
Substitution Straightforward when one variable is already isolated; works systematically Can get messy with fractions; requires solving for a variable first One equation is already solved for a variable (like $y = 3x + 2$); one variable has coefficient 1 or $-1$
Elimination Systematic; handles any coefficients; no need to isolate first Requires careful alignment; more steps when coefficients don't match easily Equations are in standard form; coefficients are already opposites or easy multiples; neither variable is isolated

The Bottom Line

There's no "wrong" method—just more or less efficient choices. With practice, you'll develop intuition for which approach suits a particular problem. When in doubt:

  • If one equation has a variable isolated → Substitution
  • If equations are in standard form with aligned terms → Elimination
  • If you want to see what's going on → Graphing (at least as a first step)

Example: Choosing the Right Tool

Which method would you choose for each system?

(a) $y = 4x - 3$ and $2x + 3y = 15$

Substitution — the first equation already has $y$ isolated.

(b) $5x + 2y = 11$ and $5x - 2y = 1$

Elimination — the $y$-coefficients are already opposites; just add.

(c) $3x + 7y = 22$ and $2x - 5y = -9$

Elimination — standard form, but will need to multiply both equations. (Substitution would work too, but would introduce fractions early.)

(d) $x = 2y + 1$ and $y = 3x - 7$

Substitution — both variables are isolated; substitute one into the other.

13.7 Applications

Systems of equations arise naturally when a problem involves two unknown quantities and gives us two independent pieces of information about them. The key skill is translating the words into equations.

Setting Up Systems from Word Problems

  1. Identify the unknowns. What two quantities are you trying to find? Assign variables to them.
  2. Find two relationships. What two facts does the problem give you about these quantities?
  3. Write equations. Translate each relationship into an equation.
  4. Solve the system. Use graphing, substitution, or elimination.
  5. Check and interpret. Does your answer make sense in context? Answer in words, not just numbers.

Mixture Problems

Mixture problems involve combining two items with different properties (prices, concentrations, etc.) to create a mixture with a specified property.

Example 1: Nut Mixture

A store sells cashews for 8 dollars per pound and peanuts for 3 dollars per pound. How many pounds of each should be mixed to create 20 pounds of a mixture worth 5 dollars per pound?

Step 1: Identify unknowns.

  • Let $c$ = pounds of cashews
  • Let $p$ = pounds of peanuts

Step 2: Find relationships.

  • Total weight: The mixture weighs 20 pounds.
  • Total value: The mixture is worth $5 \times 20 = 100$ dollars.

Step 3: Write equations.

Weight equation: $c + p = 20$

Value equation: $8c + 3p = 100$ (cashews contribute $8c$ dollars, peanuts contribute $3p$ dollars)

Step 4: Solve. Using substitution: from the first equation, $p = 20 - c$. Substitute:

$$8c + 3(20 - c) = 100$$

$$8c + 60 - 3c = 100$$

$$5c = 40$$

$$c = 8$$

Then $p = 20 - 8 = 12$.

Step 5: Check and interpret.

Weight: $8 + 12 = 20$ pounds ✓

Value: $8(8) + 3(12) = 64 + 36 = 100$ dollars ✓

Price per pound: $100 \div 20 = 5$ dollars ✓

Answer: Mix 8 pounds of cashews with 12 pounds of peanuts.

Fig. 13.3 — Nut Mixture Problem
The weight constraint ($c + p = 20$) and value constraint ($8c + 3p = 100$) intersect at $(8, 12)$.

Rate Problems

Rate problems often involve motion—distance, speed, and time. The fundamental relationship is: distance = rate × time.

Example 2: Boat on a River

A boat travels 24 miles downstream (with the current) in 2 hours, and 24 miles upstream (against the current) in 3 hours. Find the boat's speed in still water and the speed of the current.

Step 1: Identify unknowns.

  • Let $b$ = boat's speed in still water (mph)
  • Let $c$ = current's speed (mph)

Step 2: Find relationships.

  • Downstream: The current helps, so effective speed is $b + c$. Traveling 24 miles in 2 hours means speed is $24 \div 2 = 12$ mph.
  • Upstream: The current hinders, so effective speed is $b - c$. Traveling 24 miles in 3 hours means speed is $24 \div 3 = 8$ mph.

Step 3: Write equations.

$$b + c = 12$$

$$b - c = 8$$

Step 4: Solve. These equations are perfect for elimination—add them:

$$2b = 20$$

$$b = 10$$

Then from $b + c = 12$: $c = 12 - 10 = 2$.

Step 5: Check and interpret.

Downstream speed: $10 + 2 = 12$ mph. Distance in 2 hours: $12 \times 2 = 24$ miles ✓

Upstream speed: $10 - 2 = 8$ mph. Distance in 3 hours: $8 \times 3 = 24$ miles ✓

Answer: The boat's speed in still water is 10 mph. The current's speed is 2 mph.

Fig. 13.4 — Boat and Current Problem
The downstream constraint ($b + c = 12$) and upstream constraint ($b - c = 8$) intersect at $(10, 2)$.

Cost Comparison Problems

When comparing two options with different cost structures, systems help us find the "break-even point" where the costs are equal.

Example 3: Phone Plans

Phone Plan A charges 25 dollars per month plus 0.10 dollars per text message. Plan B charges 40 dollars per month with unlimited texts. When is each plan the better deal?

Step 1: Identify unknowns.

  • Let $t$ = number of text messages per month
  • Let $C$ = monthly cost (in dollars)

Step 2: Write equations for each plan.

Plan A: $C = 25 + 0.10t$

Plan B: $C = 40$

Step 3: Find break-even point. Set the costs equal:

$$25 + 0.10t = 40$$

$$0.10t = 15$$

$$t = 150$$

Step 4: Interpret.

  • At exactly 150 texts/month, both plans cost the same (40 dollars).
  • Below 150 texts/month, Plan A is cheaper (lower base, per-text cost doesn't add up to 15 dollars).
  • Above 150 texts/month, Plan B is cheaper (unlimited texts for a flat fee).

Answer: Plan A is better for fewer than 150 texts per month. Plan B is better for more than 150 texts per month. At exactly 150 texts, they cost the same.

Fig. 13.5 — Phone Plan Comparison
Plan A's cost increases with texts; Plan B is flat. They intersect at $(150, 40)$—the break-even point.

Quantity and Value Problems

These problems involve a collection of items where you know the total count and total value, but not how many of each type.

Example 4: Coin Collection

A collection contains 42 coins, all dimes and quarters. The total value is 7.35 dollars. How many of each type of coin are there?

Step 1: Identify unknowns.

  • Let $d$ = number of dimes
  • Let $q$ = number of quarters

Step 2: Find relationships.

  • Total coins: $d + q = 42$
  • Total value: Each dime is worth 0.10 dollars, each quarter is worth 0.25 dollars. So $0.10d + 0.25q = 7.35$.

Step 3: Write equations.

$$d + q = 42$$

$$0.10d + 0.25q = 7.35$$

Step 4: Solve. Multiply the second equation by 100 to clear decimals:

$$10d + 25q = 735$$

From the first equation, $d = 42 - q$. Substitute:

$$10(42 - q) + 25q = 735$$

$$420 - 10q + 25q = 735$$

$$15q = 315$$

$$q = 21$$

Then $d = 42 - 21 = 21$.

Step 5: Check and interpret.

Count: $21 + 21 = 42$ coins ✓

Value: $0.10(21) + 0.25(21) = 2.10 + 5.25 = 7.35$ dollars ✓

Answer: There are 21 dimes and 21 quarters.

Fig. 13.6 — Coin Problem
The count constraint ($d + q = 42$) and value constraint ($0.10d + 0.25q = 7.35$) intersect at $(21, 21)$.

Common Application Types

Most system-of-equations word problems fall into a few categories:

  • Mixture: Combining items with different properties (price, concentration, etc.)
  • Rate/Motion: Objects moving with or against currents, winds, etc.
  • Cost comparison: Finding when two pricing structures give equal cost
  • Quantity/Value: Known total count and total value of mixed items

Recognizing the type helps you set up the equations—you'll often have one equation for "count" or "total quantity" and another for "value" or "total cost."

Solutions

Verifying Solutions (Problems 1–3)

Problem 1: Is $(4, 1)$ a solution to $x + 2y = 6$ and $3x - y = 11$?

Check first equation: $4 + 2(1) = 4 + 2 = 6$ ✓

Check second equation: $3(4) - 1 = 12 - 1 = 11$ ✓

Answer: Yes, $(4, 1)$ is a solution.

Problem 2: Is $(-2, 5)$ a solution to $2x + y = 1$ and $x - 3y = -13$?

Check first equation: $2(-2) + 5 = -4 + 5 = 1$ ✓

Check second equation: $-2 - 3(5) = -2 - 15 = -17 \neq -13$ ✗

Answer: No, $(-2, 5)$ is not a solution.

Problem 3: Is $\left(\frac{1}{2}, 3\right)$ a solution to $4x + y = 5$ and $2x - y = -2$?

Check first equation: $4\left(\frac{1}{2}\right) + 3 = 2 + 3 = 5$ ✓

Check second equation: $2\left(\frac{1}{2}\right) - 3 = 1 - 3 = -2$ ✓

Answer: Yes, $\left(\frac{1}{2}, 3\right)$ is a solution.

Solving by Graphing (Problems 4–6)

Problem 4: $y = x + 1$ and $y = -x + 5$

Line 1: slope 1, y-intercept 1. Line 2: slope $-1$, y-intercept 5.

Set equal: $x + 1 = -x + 5 \Rightarrow 2x = 4 \Rightarrow x = 2$

Then $y = 2 + 1 = 3$.

Answer: $(2, 3)$

Problem 5: $y = 2x - 3$ and $y = -x + 6$

Set equal: $2x - 3 = -x + 6 \Rightarrow 3x = 9 \Rightarrow x = 3$

Then $y = 2(3) - 3 = 3$.

Answer: $(3, 3)$

Problem 6: $x + y = 4$ and $x - y = 2$

Rewrite: $y = 4 - x$ and $y = x - 2$.

Set equal: $4 - x = x - 2 \Rightarrow 6 = 2x \Rightarrow x = 3$

Then $y = 4 - 3 = 1$.

Answer: $(3, 1)$

Solving by Substitution (Problems 7–11)

Problem 7: $y = 2x + 1$ and $3x + 2y = 16$

Substitute: $3x + 2(2x + 1) = 16$

$3x + 4x + 2 = 16 \Rightarrow 7x = 14 \Rightarrow x = 2$

Then $y = 2(2) + 1 = 5$.

Check: $3(2) + 2(5) = 6 + 10 = 16$ ✓

Answer: $(2, 5)$

Problem 8: $x = 4y - 3$ and $2x + 3y = 5$

Substitute: $2(4y - 3) + 3y = 5$

$8y - 6 + 3y = 5 \Rightarrow 11y = 11 \Rightarrow y = 1$

Then $x = 4(1) - 3 = 1$.

Check: $2(1) + 3(1) = 5$ ✓

Answer: $(1, 1)$

Problem 9: $x + y = 7$ and $2x - 3y = -6$

From first equation: $x = 7 - y$. Substitute:

$2(7 - y) - 3y = -6$

$14 - 2y - 3y = -6 \Rightarrow -5y = -20 \Rightarrow y = 4$

Then $x = 7 - 4 = 3$.

Check: $2(3) - 3(4) = 6 - 12 = -6$ ✓

Answer: $(3, 4)$

Problem 10: $3x - y = 7$ and $x + 2y = 6$

From first equation: $y = 3x - 7$. Substitute into second:

$x + 2(3x - 7) = 6$

$x + 6x - 14 = 6 \Rightarrow 7x = 20 \Rightarrow x = \frac{20}{7}$

Then $y = 3\left(\frac{20}{7}\right) - 7 = \frac{60}{7} - \frac{49}{7} = \frac{11}{7}$.

Check: $\frac{20}{7} + 2\left(\frac{11}{7}\right) = \frac{20}{7} + \frac{22}{7} = \frac{42}{7} = 6$ ✓

Answer: $\left(\frac{20}{7}, \frac{11}{7}\right)$ or approximately $(2.86, 1.57)$

Problem 11: $2x + 5y = 1$ and $x - y = 4$

From second equation: $x = y + 4$. Substitute:

$2(y + 4) + 5y = 1$

$2y + 8 + 5y = 1 \Rightarrow 7y = -7 \Rightarrow y = -1$

Then $x = -1 + 4 = 3$.

Check: $2(3) + 5(-1) = 6 - 5 = 1$ ✓

Answer: $(3, -1)$

Solving by Elimination (Problems 12–16)

Problem 12: $x + y = 10$ and $x - y = 4$

Add equations: $2x = 14 \Rightarrow x = 7$

Substitute: $7 + y = 10 \Rightarrow y = 3$

Answer: $(7, 3)$

Problem 13: $3x + 2y = 19$ and $3x - 2y = 5$

Add equations (y-terms cancel): $6x = 24 \Rightarrow x = 4$

Substitute: $3(4) + 2y = 19 \Rightarrow 12 + 2y = 19 \Rightarrow y = \frac{7}{2}$

Answer: $\left(4, \frac{7}{2}\right)$ or $(4, 3.5)$

Problem 14: $2x + 3y = 7$ and $5x - 2y = 8$

Multiply first by 2 and second by 3 to eliminate $y$:

$4x + 6y = 14$

$15x - 6y = 24$

Add: $19x = 38 \Rightarrow x = 2$

Substitute: $2(2) + 3y = 7 \Rightarrow 4 + 3y = 7 \Rightarrow y = 1$

Answer: $(2, 1)$

Problem 15: $4x + 5y = 23$ and $3x + 2y = 12$

Multiply first by 2 and second by $-5$ to eliminate $y$:

$8x + 10y = 46$

$-15x - 10y = -60$

Add: $-7x = -14 \Rightarrow x = 2$

Substitute: $3(2) + 2y = 12 \Rightarrow 6 + 2y = 12 \Rightarrow y = 3$

Answer: $(2, 3)$

Problem 16: $\frac{1}{2}x + \frac{1}{3}y = 5$ and $\frac{1}{4}x - \frac{1}{2}y = -1$

Clear fractions by multiplying first equation by 6 and second by 4:

$3x + 2y = 30$

$x - 2y = -4$

Add: $4x = 26 \Rightarrow x = \frac{26}{4} = \frac{13}{2}$

Substitute into $x - 2y = -4$:

$\frac{13}{2} - 2y = -4 \Rightarrow -2y = -4 - \frac{13}{2} = -\frac{21}{2} \Rightarrow y = \frac{21}{4}$

Check: $\frac{1}{2}\left(\frac{13}{2}\right) + \frac{1}{3}\left(\frac{21}{4}\right) = \frac{13}{4} + \frac{21}{12} = \frac{39}{12} + \frac{21}{12} = \frac{60}{12} = 5$ ✓

These are the same line.

Problem 18: $3x - 6y = 12$ and $x - 2y = 8$

Section 13 Summary

Key Concepts

What Is a System?

A system of equations is a set of two or more equations with the same variables. A solution must satisfy all equations simultaneously. For two linear equations in two variables, the solution (if it exists) is an ordered pair $(x, y)$.

Three Possible Outcomes

Outcome Geometry Algebra Shows
One solution Lines intersect at one point Unique values for $x$ and $y$
No solution (inconsistent) Lines are parallel False statement (e.g., $0 = 5$)
Infinitely many (dependent) Lines are identical True statement (e.g., $0 = 0$)

Three Solving Methods

  • Graphing: Plot both lines; read the intersection. Best for visualization and estimation.
  • Substitution: Solve one equation for a variable, substitute into the other. Best when a variable is already isolated or has coefficient 1 or $-1$.
  • Elimination: Add or subtract equations to eliminate a variable. Best when equations are in standard form.

All methods give the same answer—choose based on what makes the arithmetic easiest.

Setting Up Word Problems

  1. Identify two unknowns
  2. Find two relationships (facts) about them
  3. Write an equation for each relationship
  4. Solve and check that the answer makes sense in context

Common Application Types

  • Mixture: Combining items with different properties
  • Rate/Motion: Distance, speed, time relationships
  • Cost comparison: Finding break-even points
  • Quantity/Value: Total count and total value known
