Section 11: Inequalities

In Section 10, we solved equations—finding the exact value that makes two expressions equal. But many real situations don't require exact equality. When you check whether you have enough money for a purchase, you don't need exactly the right amount—you need at least that much. When a recipe says "bake for 25-30 minutes," there's a range of acceptable times. When an elevator has a weight limit, any weight below that limit is acceptable.

These situations call for inequalities—mathematical statements about one quantity being greater than, less than, or not equal to another. Unlike equations, which typically have one solution (or a few), inequalities usually have infinitely many solutions: a whole range of values that work.

11.1 What Inequalities Mean

An inequality is a mathematical statement comparing two quantities using one of these symbols:

Inequality Symbols

Symbol Meaning Example Read as
$<$ less than $x < 5$ "$x$ is less than 5"
$>$ greater than $x > 3$ "$x$ is greater than 3"
$\leq$ less than or equal to $x \leq 7$ "$x$ is at most 7"
$\geq$ greater than or equal to $x \geq 2$ "$x$ is at least 2"

The symbols $<$ and $>$ are called strict inequalities—the boundary value is not included. The symbols $\leq$ and $\geq$ are non-strict (or inclusive)—the boundary value is included.

Every inequality can be read in two directions. The statement $x < 5$ (read left-to-right: "$x$ is less than 5") means exactly the same as $5 > x$ (read left-to-right: "5 is greater than $x$"). The "arrow" always points toward the smaller quantity.

Equations vs. Inequalities

An equation like $x + 3 = 7$ typically has one solution: $x = 4$.

An inequality like $x + 3 < 7$ has infinitely many solutions: $x$ can be 3, or 2, or 0, or $-5$, or $3.99$, or any number less than 4.

Solving an inequality means describing the entire set of values that make it true.

Translating Between Words and Symbols

"You must be at least 13 years old to create an account."

If $a$ represents age: $a \geq 13$

Ages 13, 14, 17.5, 42 all satisfy this. Age 12 does not.

"The speed limit is 65 mph."

If $s$ represents speed: $s \leq 65$

Speeds of 60, 65, 45, and 0 are legal. Speed of 66 is not.

"You need more than 50 points to advance."

If $p$ represents points: $p > 50$

Scores of 51, 75, 50.01 all qualify. Exactly 50 does not (it's "more than," not "at least").

11.2 Graphing Inequalities on a Number Line

Since inequalities have infinitely many solutions, we can't list them all. Instead, we show them visually on a number line, shading all the values that satisfy the inequality.

Graphing Conventions

Open circle (○): Used for strict inequalities ($<$ or $>$). The boundary point is NOT included.

Closed circle (●): Used for inclusive inequalities ($\leq$ or $\geq$). The boundary point IS included.

Shading: Shade the ray extending toward all the solutions.

Fig. 11.1: The Four Inequality Types on Number Lines
Open circles exclude the boundary; closed circles include it. The interval notation appears at right.

Interval Notation

Interval notation is a compact way to describe a range of numbers. It's used throughout mathematics, so it's worth learning now.

Interval Notation Rules

Parentheses ( ): The endpoint is NOT included (same as open circle)

Brackets [ ]: The endpoint IS included (same as closed circle)

Infinity (∞): Always uses a parenthesis—you can't "reach" infinity

Inequality Interval Notation Meaning
$x < 5$ $(-\infty, 5)$ All numbers less than 5
$x \leq 5$ $(-\infty, 5]$ All numbers less than or equal to 5
$x > 2$ $(2, \infty)$ All numbers greater than 2
$x \geq 2$ $[2, \infty)$ All numbers greater than or equal to 2
$2 < x < 5$ $(2, 5)$ All numbers between 2 and 5 (not including either)
$2 \leq x \leq 5$ $[2, 5]$ All numbers from 2 to 5, inclusive

Throughout this section, we'll express solutions in both inequality notation and interval notation. Both are widely used, and being fluent in both will serve you well.

11.3 Solving Linear Inequalities

Solving an inequality is very similar to solving an equation. You use the same operations—adding, subtracting, multiplying, dividing—to isolate the variable. With one crucial exception that we'll address in the next section, everything you learned about solving equations applies here.

Operations That Preserve Inequality Direction

You can do any of these to both sides without changing the inequality direction:

  • Add the same number to both sides
  • Subtract the same number from both sides
  • Multiply both sides by a positive number
  • Divide both sides by a positive number

Example: One-Step Inequality (Addition/Subtraction)

Solve $x + 3 > 7$

Subtract 3 from both sides:

$$x + 3 - 3 > 7 - 3$$

$$x > 4$$

Solution: $x > 4$, or in interval notation: $(4, \infty)$

Check: Pick a value from the solution set, say $x = 5$. Is $5 + 3 > 7$? Yes, $8 > 7$. ✓

Pick a value NOT in the solution set, say $x = 4$. Is $4 + 3 > 7$? No, $7 \not> 7$. ✓

Example: Two-Step Inequality

Solve $3x - 5 \leq 10$

Add 5 to both sides:

$$3x - 5 + 5 \leq 10 + 5$$

$$3x \leq 15$$

Divide both sides by 3 (positive, so direction stays the same):

$$\frac{3x}{3} \leq \frac{15}{3}$$

$$x \leq 5$$

Solution: $x \leq 5$, or $(-\infty, 5]$

Check: Try $x = 3$ (in solution): $3(3) - 5 = 4 \leq 10$. ✓

Try $x = 6$ (not in solution): $3(6) - 5 = 13 \not\leq 10$. ✓

Example: Multi-Step Inequality

Solve $2(x - 3) + 4 > x + 1$

Distribute on the left:

$$2x - 6 + 4 > x + 1$$

$$2x - 2 > x + 1$$

Subtract $x$ from both sides:

$$x - 2 > 1$$

Add 2 to both sides:

$$x > 3$$

Solution: $x > 3$, or $(3, \infty)$

Example: Inequality with Fractions

Solve $\frac{2x - 1}{3} \geq 5$

Multiply both sides by 3 (positive, so direction unchanged):

$$2x - 1 \geq 15$$

Add 1 to both sides:

$$2x \geq 16$$

Divide both sides by 2 (positive):

$$x \geq 8$$

Solution: $x \geq 8$, or $[8, \infty)$

11.4 The Sign-Reversal Rule

There is one critical difference between solving equations and solving inequalities. When you multiply or divide both sides by a negative number, you must reverse the inequality sign.

The Sign-Reversal Rule

When you multiply or divide both sides of an inequality by a negative number, you must flip the inequality symbol:

  • $<$ becomes $>$
  • $>$ becomes $<$
  • $\leq$ becomes $\geq$
  • $\geq$ becomes $\leq$

Why does this happen? Consider the true statement $3 > 2$. If we multiply both sides by $-1$:

$3 > 2$ becomes $-3 \text{ ? } -2$

Is $-3 > -2$? No! On the number line, $-3$ is to the left of $-2$, so $-3 < -2$. Multiplying by a negative number reflects values across zero, reversing their order.

Fig. 11.2: Why Multiplying by a Negative Reverses Order
Multiplying by -1 reflects points across zero. Since 3 is to the right of 2, their reflections (-3 and -2) have reversed positions: -3 is now to the LEFT of -2.

Example: Inequality Requiring Sign Reversal

Solve $-2x < 6$

Divide both sides by $-2$. Since we're dividing by a negative number, reverse the inequality:

$$\frac{-2x}{-2} \color{red}{>} \frac{6}{-2}$$

$$x > -3$$

Solution: $x > -3$, or $(-3, \infty)$

Check: Try $x = 0$ (should work): $-2(0) = 0 < 6$. ✓

Try $x = -4$ (should NOT work): $-2(-4) = 8 \not< 6$. ✓

Example: Multi-Step with Sign Reversal

Solve $7 - 3x \geq 16$

Subtract 7 from both sides:

$$-3x \geq 9$$

Divide both sides by $-3$. Reverse the inequality:

$$x \leq -3$$

Solution: $x \leq -3$, or $(-\infty, -3]$

Check: Try $x = -5$: $7 - 3(-5) = 7 + 15 = 22 \geq 16$. ✓

Try $x = 0$: $7 - 3(0) = 7 \not\geq 16$. ✓

Common Mistake Alert

Forgetting to reverse the inequality when dividing by a negative is one of the most common errors in algebra. Always ask yourself: "Am I multiplying or dividing by a negative?" If yes, flip the sign!

Tip: If you're unsure whether your answer is correct, check it by substituting a value from your solution set into the original inequality.

11.5 Compound Inequalities

Sometimes a quantity must satisfy two conditions at once. A compound inequality combines two inequalities using the words AND or OR.

"And" Inequalities (Intersection)

An "and" inequality requires both conditions to be true simultaneously. For example, "$x > 2$ AND $x < 7$" means $x$ must be greater than 2 and also less than 7. The solution is the overlap (intersection) of the two individual solutions.

Fig. 11.3: AND Inequalities — The Intersection
The AND solution (green) is where both conditions overlap: numbers that are simultaneously greater than 2 and less than 7.

Since "and" inequalities describe values between two bounds, we often write them in compact notation:

$x > 2$ AND $x < 7$ is the same as $2 < x < 7$

Read "$2 < x < 7$" as "$x$ is between 2 and 7" (exclusive on both ends). In interval notation: $(2, 7)$.

Example: Solving an "And" Compound Inequality

Solve $-1 \leq 2x + 3 < 9$

This is a three-part inequality. We solve it by isolating $x$ in the middle, performing the same operation on all three parts:

Subtract 3 from all parts:

$$-1 - 3 \leq 2x + 3 - 3 < 9 - 3$$

$$-4 \leq 2x < 6$$

Divide all parts by 2 (positive, so no sign reversal):

$$-2 \leq x < 3$$

Solution: $-2 \leq x < 3$, or $[-2, 3)$

Check: Try $x = 0$ (should work): $-1 \leq 2(0) + 3 < 9$ gives $-1 \leq 3 < 9$. ✓

Try $x = -2$ (boundary, should work): $-1 \leq 2(-2) + 3 < 9$ gives $-1 \leq -1 < 9$. ✓

Try $x = 3$ (boundary, should NOT work): $-1 \leq 2(3) + 3 < 9$ gives $-1 \leq 9 \not< 9$. ✓

"Or" Inequalities (Union)

An "or" inequality requires at least one condition to be true. For example, "$x < 1$ OR $x > 5$" means $x$ satisfies the inequality if it's less than 1, or if it's greater than 5. The solution is the union of the two individual solutions.

Fig. 11.4: OR Inequalities — The Union
The OR solution (green) includes both regions: any number less than 1 or greater than 5 satisfies the compound inequality.

In interval notation, we use the union symbol $\cup$ to join separate intervals:

$x < 1$ OR $x > 5$ is written as $(-\infty, 1) \cup (5, \infty)$

Example: Solving an "Or" Compound Inequality

Solve $3x + 2 < -4$ OR $2x - 1 \geq 5$

Solve each inequality separately:

First inequality: $3x + 2 < -4$

Subtract 2: $3x < -6$

Divide by 3: $x < -2$

Second inequality: $2x - 1 \geq 5$

Add 1: $2x \geq 6$

Divide by 2: $x \geq 3$

Solution: $x < -2$ OR $x \geq 3$, or $(-\infty, -2) \cup [3, \infty)$

Check: Try $x = -3$ (should work via first part): $3(-3) + 2 = -7 < -4$. ✓

Try $x = 0$ (should NOT work—between the intervals): $3(0) + 2 = 2 \not< -4$ and $2(0) - 1 = -1 \not\geq 5$. ✓

Try $x = 3$ (boundary, should work via second part): $2(3) - 1 = 5 \geq 5$. ✓

Three-Part Inequalities

A three-part inequality like $-3 < 2x + 1 \leq 7$ is really an "and" compound inequality written in compact form. It means "$2x + 1$ is greater than $-3$ AND less than or equal to 7."

Fig. 11.5: Solving a Three-Part Inequality
Whatever you do to the middle, do to all three parts. The solution is the interval from -2 (exclusive) to 3 (inclusive).

Solving Three-Part Inequalities

Perform the same operation on all three parts simultaneously:

If you add 5 to the middle, add 5 to the left and right.

If you divide the middle by 2, divide the left and right by 2.

If you multiply or divide by a negative, reverse both inequality signs.

Example: Three-Part Inequality with Sign Reversal

Solve $5 \leq -2x + 1 < 11$

Subtract 1 from all parts:

$$4 \leq -2x < 10$$

Divide all parts by $-2$. Reverse both inequality signs:

$$-2 \geq x > -5$$

Rewrite in standard order (smaller value on left):

$$-5 < x \leq -2$$

Solution: $-5 < x \leq -2$, or $(-5, -2]$

Check: Try $x = -3$: $5 \leq -2(-3) + 1 < 11$ gives $5 \leq 7 < 11$. ✓

Summary: AND vs. OR

Type Meaning Graphical Result Interval Notation
AND Both conditions must be true Intersection (overlap) Single interval: $(a, b)$
OR At least one condition must be true Union (combine both) Union of intervals using $\cup$

11.6 Applications

Inequalities appear whenever we deal with limits, ranges, or requirements—situations where there's no single "right" answer, but rather a range of acceptable values.

Example: Budget Constraint

Problem: You're buying supplies for a project. You have 75 dollars to spend. Each supply kit costs 12 dollars, and you also need to pay a one-time shipping fee of 8 dollars. How many kits can you buy?

Setup: Let $n$ = number of kits. Total cost = $12n + 8$. This must be at most 75 dollars:

$$12n + 8 \leq 75$$

Solve:

Subtract 8: $12n \leq 67$

Divide by 12: $n \leq 5.58...$

Since you can't buy a fraction of a kit, and $n$ must be a whole number:

Answer: You can buy at most 5 kits.

Verify: 5 kits cost $12(5) + 8 = 68$ dollars. ✓ (under budget)

6 kits would cost $12(6) + 8 = 80$ dollars. ✗ (over budget)

Example: Grade Requirement

Problem: Your test scores so far are 78, 85, and 72. You need an average of at least 80 to get a B in the class. What score do you need on the fourth (final) test?

Setup: Let $x$ = score on the fourth test. The average of all four tests must be at least 80:

$$\frac{78 + 85 + 72 + x}{4} \geq 80$$

Solve:

Simplify the numerator: $\frac{235 + x}{4} \geq 80$

Multiply both sides by 4: $235 + x \geq 320$

Subtract 235: $x \geq 85$

Answer: You need at least 85 on the final test.

Verify: If $x = 85$: average $= \frac{235 + 85}{4} = \frac{320}{4} = 80$. ✓

Example: Temperature Range

Problem: A laboratory experiment requires the temperature to stay between 15°C and 25°C. The temperature in Fahrenheit is related to Celsius by $F = \frac{9}{5}C + 32$. What is the acceptable range in Fahrenheit?

Setup: We need $15 \leq C \leq 25$. Substitute $C = \frac{5}{9}(F - 32)$:

$$15 \leq \frac{5}{9}(F - 32) \leq 25$$

Solve:

Multiply all parts by $\frac{9}{5}$: $\frac{9}{5}(15) \leq F - 32 \leq \frac{9}{5}(25)$

$$27 \leq F - 32 \leq 45$$

Add 32 to all parts: $59 \leq F \leq 77$

Answer: The temperature must stay between 59°F and 77°F (inclusive).

Verify: At 59°F: $C = \frac{5}{9}(59-32) = \frac{5}{9}(27) = 15$°C. ✓

At 77°F: $C = \frac{5}{9}(77-32) = \frac{5}{9}(45) = 25$°C. ✓

Section 11 Summary

Key Concepts

Inequalities describe ranges of values, not single answers. The four symbols are: $<$ (less than), $>$ (greater than), $\leq$ (less than or equal), $\geq$ (greater than or equal).

Interval notation expresses solution sets compactly:

  • Parentheses ( ) for excluded endpoints; brackets [ ] for included endpoints
  • Infinity always uses parentheses: $(-\infty, 5]$ or $[3, \infty)$

Solving inequalities works like solving equations, with one critical exception:

  • When you multiply or divide by a negative number, reverse the inequality sign

Compound inequalities combine conditions:

  • AND: Both must be true — find the intersection (overlap)
  • OR: At least one must be true — find the union (combine both regions)
